# 책 학습 진행률과 전체 원문 분석 (2026-09-24)

이전 25% 표시는 보물섬 코스가 20개 발췌 문장뿐일 때 저장 위치 5를 `5 / 20`으로 계산한 결과였다. 20문장은 책 전체가 아니라 화면상 한 묶음의 크기다.

현재 책 코스는 10권의 **본문 추출 단위 40,034개**를 원문 순서로 담는다. 원래 파서가 여러 문장을 한 단위에 묶거나 약어에서 나눈 사례가 있어 40,034는 언어학적으로 검증된 문장 수가 아니다. 구텐베르크 머리말·목차·삽화 지시문·라이선스·교정 노트는 제외했고, `Mr.`·`Mrs.` 같은 약어의 잘못된 분리는 코스 생성 단계에서 이어 붙였다.

전체 단위에 spaCy 영어 의존 구문 분석을 적용했다. **38,346개**는 문장 성분별 방번호 블록으로 생성되어 퍼즐에 들어가고, 서술어가 없는 **1,688개**는 `fragment`로 분류해 원문 낭독과 읽기 화면으로 진행한다. 자동 분석 결과에는 `analysisVersion`, `analysisType`, `reviewStatus=machine_unreviewed`를 기록한다. 자동 방번호는 전수 편집 검수가 끝난 정답이 아니므로 출판 품질로 취급해서는 안 된다.

책마다 `Resources/Learning/Books/<workId>.json`으로 나누어 선택한 책 하나만 메모리에 읽는다. `legacy_book_manifest.json`은 서가의 전체 수와 진행률을 제공한다. 표지의 `완료/전체`와 퍼센트는 모든 본문 추출 단위를 분모로 사용한다. 20개씩 화면상 챕터로 묶고, 저장 위치는 책별로 유지한다. 기존 발췌 코스의 저장값은 `learning.legacy.room.course.position.*`에 보존했다. 전체 읽기는 앞에서 건너뛴 문장을 완료 처리하지 않도록 `learning.legacy.room.full.position.*`로 처음부터 시작한다.

음성 낭독은 화면에 나타난 원문을 기기 TTS로 읽는다. Android는 `TextToSpeech`, iOS는 `AVSpeechSynthesizer`, macOS 에디터/앱은 시스템 `say`를 사용한다. 읽기 화면에서는 자동 재생하고, 퍼즐에서는 정답을 맞히면 재생한다. `듣기` 버튼으로 다시 들을 수 있다.

데이터 재생성 순서: `python3 Tools/build_legacy_book_courses.py`, 이어서 spaCy 3.7.5와 `en_core_web_sm` 3.7.1을 설치한 Python으로 `Tools/analyze_full_book_courses.py`. 재생성 뒤 구조 검증 및 대표 문장 편집 검수는 별도로 필요하다.
