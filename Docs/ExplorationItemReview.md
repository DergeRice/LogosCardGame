## 구현 상태

- `run_start` 계열은 새 블라인드 시작 시 적용된다. 저장 후 이어하기에서는 중복 적용되지 않는다.
- 소모 스택, 무료 리롤, 드로우/제출 연속 스택은 저장 및 복구된다.
- `특수 카드 할인`은 특수 품사 카드 상점 가격에 반영된다.
- 아이템 JSON의 가격을 실제 상점 구매 가격에 사용한다.
