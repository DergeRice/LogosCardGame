# LOGOS WebBattle

### v0.9.23 모바일 예문 음성

휴대폰에서는 기기의 SpeechSynthesis 설치·음성 목록에 의존하지 않고, 사이트에 포함한 영어 음성 파일을 Web Audio로 재생합니다. `public/audio/examples/voice-v1.wav`에 83개 단어 음성을 포함하며 약 1.4MiB입니다. 시작 화면에서 음성·카드 파일을 미리 불러옵니다. 첫 클릭/터치에서 오디오 컨텍스트를 활성화하며, 표시 예문을 단어 순서대로 구성해 한 번 재생하고 종료 이벤트 이후 2초 후 닫힙니다. 단어별 음성을 이어 재생하므로 문장 전체 TTS보다 억양이 단조로울 수 있습니다.

PC에서는 기존 TTS를 우선 사용하고, 오류 또는 2초 동안 시작되지 않는 경우 같은 파일 재생으로 전환합니다. 브라우저 제스처 제한·파일 오류로 재생하지 못하면 패널에 `소리 켜고 듣기`를 표시하고 자동으로 닫지 않습니다. 누르면 재시도합니다. 패널을 닫거나 다른 카드를 누르면 재생을 중단합니다. 효과음 OFF 설정은 예문 읽기와 별도입니다.

음성 생성: Windows의 영어 SAPI 음성 Microsoft Zira Desktop으로 합성한 출력이며 외부 서비스/API 비용이 없습니다. 생성 코드와 어휘 목록도 저장소에 포함합니다. 어휘 확장 시 `shared/example-audio.ts`를 갱신하고 Windows에서 `npm run audio:build`를 실행합니다. 생성된 WAV/JSON은 Git에 포함하므로 Netlify 빌드·배포 서버에는 Windows/SAPI가 필요하지 않습니다.

검증에서는 실제 WAV를 디코딩·재생해 무음이 아닌 파형, 시작/종료, 1회 재생, 종료+2초 후 패널 닫힘을 검사합니다. Chrome 모바일 화면에서 TTS API를 제거한 경우, PC TTS 오류, 오디오 제스처 제한 후 재시도를 확인했습니다. Windows Playwright WebKit은 Web Audio/SpeechSynthesis가 빌드에 없어 음성 실험을 명시적으로 제외합니다. 실제 Android/iPhone 스피커 출력은 이 PC의 브라우저 검증으로 확인했다고 주장하지 않습니다.

### v0.9.22 재생·드래그 수정

사용자의 클릭·터치에서 무음 음성으로 SpeechSynthesis 세션을 활성화하고 Web Audio 컨텍스트를 생성·재개합니다. 지연된 예문 자동 재생이 모바일 사용자 제스처 제한에 걸리는 경로를 보완하며, 실제 발화 객체는 패널이 닫힐 때까지 참조를 유지합니다. PC 드래그의 위치 판정은 드래그 시작 시 카드 위치를 기준으로 고정하고, 실제 카드와 같은 크기의 빈 슬롯을 표시합니다. 필드 재배치 시 원래 버튼 노드를 유지해 포인터 캡처가 끊기지 않도록 했습니다.

검증: 단위/실시간 테스트 99개, PC 및 작은 visualViewport를 사용하는 모바일 가로 드래그·예문 테스트 4개. 모바일 음성은 사용자 제스처 제한을 재현한 브라우저 테스트이며 실제 휴대폰 스피커 출력은 별도 확인이 필요합니다. SpeechSynthesis 활성화 근거: [WebKit SpeechSynthesis 구현](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/Modules/speech/SpeechSynthesis.cpp).

원본 소스: [DergeRice/LogosCardGame — web-battle 브랜치](https://github.com/DergeRice/LogosCardGame/tree/web-battle/WebBattle).
이 브랜치에 push하면 Netlify가 `WebBattle/`를 자동으로 빌드합니다. Unity 프로젝트는 기존 `main` 브랜치에 보존되어 있습니다.

현재 덱의 60장을 보는 [카드 뷰어](https://logos-card-battle.netlify.app/cards)는 게임 설정의 **카드 뷰어**에서도 열 수 있습니다.

브라우저와 Unity 웹뷰에서 실행되는 React + TypeScript / Node.js + WebSocket 기본 4인·최대 6인 고·스톱 카드 대전입니다.

홈 화면에서 아이디·비밀번호로 계정을 만들거나 로그인하면 기기와 브라우저를 바꿔도 레이팅·포인트를 이어갑니다. 가입 시 현재 게스트의 레이팅을 계정에 연결합니다. 계정은 Cloudflare Durable Object의 SQLite 저장소에 보관되며, 비밀번호 원문은 저장하지 않습니다. 로그인 토큰은 해당 기기의 브라우저 저장소에 30일 동안 유지됩니다. Unity의 기존 Google/UGS 계정과는 별도 계정입니다.

## 현재 공개 테스트 주소

https://logos-card-battle.netlify.app

프런트엔드는 Netlify, 실제 대전 서버는 Cloudflare Workers + SQLite Durable Object에 배포했습니다. **PC를 꺼도 서비스가 동작합니다.** 임시 터널과 PC 서버는 종료했습니다. 현재 공용 서버는 wss://logos-card-battle-server.jesus-and-children-ranking-worker.workers.dev/socket 입니다. 배포와 무료 한도는 docs/DEPLOY.md를 참고하세요.

점수: **인정 카드 수 × 인쇄 곱셈·나눗셈 효과 + 인쇄 덧셈·뺄셈 효과**, 이후 고 배율 적용. 예: 5×2+3=13점. 카드 위쪽 번호나 별은 점수가 아닙니다.

## 이 PC에서 실행

Node.js 24가 설치되어 있습니다. PowerShell:

```powershell
cd C:\Users\vlzkc\OneDrive\Desktop\LogosCardGame\WebBattle
npm.cmd ci
npm.cmd run dev
```

브라우저에서 **http://localhost:5173** 을 여세요. 프런트엔드 5173, 서버 3001입니다. 현재 .env의 VITE_WS_URL은 Cloudflare를 가리킵니다. 프런트만 실행하려면 npx vite --host 0.0.0.0을 사용합니다. 로컬 Node 서버로 테스트할 때는 VITE_WS_URL을 비우세요. 종료는 실행 터미널에서 Ctrl+C.

Windows에서는 `start-local.cmd`를 더블클릭해도 됩니다. 같은 Wi-Fi의 휴대폰에서는 개발 서버가 표시하는 Network URL로 접속할 수 있습니다. 방화벽에서 허용한 경우에만 열리며 공용 인터넷 배포 주소는 아닙니다.

- 두 명 테스트: 일반 창 + 시크릿 창. 같은 탭 새로고침은 게스트 세션 유지.
- 첫 접속 시 `게스트 1234` 형태로 자동 접속합니다. **빠른시작 하나**로 매칭합니다.
- 6초 매칭 창 안에 다른 브라우저에서도 빠른시작을 누르면 같은 방으로 입장합니다. 최대 6명까지 참여하며, 대기 시간이 끝났을 때 4명 미만이면 AI로 빈자리를 채워 4인으로 시작합니다.
- 매칭 성사 → 내 프로필 / VS / 상대 프로필 → 공용 덱에서 5장씩. 이후 30초마다 자동으로 모두 1장씩 받고, 전원이 미리 동의하면 즉시 받습니다. 1고 이후에는 현재 최고점 플레이어가 별도로 추가 배분할 수 있습니다.
- 한 문장이 20점을 초과해야 득점·사용 확정 및 고/스톱. **1고 2배 → 2고 3배 → 3고 4배**, 이후 최고점 갱신자가 주도권을 얻습니다.
- GET 2/3은 공용 덱에서 2/3장을 바로 받습니다. ROB은 선택한 상대의 손패 또는 필드에서 원하는 한 장을 가져옵니다. PROTECT를 손에 쥐고 있으면 ROB이 막힙니다. EXCHANGE는 내 카드 한 장과 다른 사람 손패의 원하는 카드 한 장을 골라 그 사람에게 보냅니다. 상대는 수락하거나 빠른 답장으로 거절합니다. 요청은 15초 후 만료됩니다.
- 결과에서 보상 포인트와 레이팅을 확인합니다. 계정 로그인 시 레이팅이 계정에 저장됩니다. 전원이 동의하면 재대결합니다.
- 카드는 부채꼴로 겹쳐 표시합니다. 클릭/터치 → 필드 이동과 손패에서 제외. 필드 카드를 누르면 손패 복귀. 직접 드래그하면 카드를 숨기고 삽입 위치를 표시하며 순서를 변경합니다.
- 상대 프로필을 누르면 가운데 문장 영역에서 그 사람의 남은 손패·현재 조합 중인 문장·기존 제출 문장을 볼 수 있습니다. 아래의 내 손패는 그대로 유지됩니다. 미리보기의 × 또는 내 프로필을 누르면 내 문장으로 돌아갑니다. 내 손패 아래 😊 버튼을 누르면 감정표현 4개가 열립니다.
- 겹친 카드를 고르기 어렵다면 손패 펼쳐 보기를 사용할 수 있습니다.
- 모바일 가로 화면에서는 선수 정보·필드·손패를 한 화면 높이에 맞춰 배치합니다. 우측 상단 ⛶ 버튼으로 브라우저 전체화면을 켜고 끌 수 있습니다. 전체화면을 지원하지 않는 모바일 브라우저에서는 가로 회전 안내가 표시됩니다.
- 게스트 세션 토큰은 sessionStorage에 보관하며 같은 탭 새로고침/일시적 단절 복귀를 지원합니다. 계정 로그인 후에는 다른 기기에서도 같은 아이디로 레이팅을 이어갑니다.
- 탭을 완전히 닫거나 시크릿 세션을 종료하면 게스트 토큰이 사라질 수 있습니다.

운영 경기는 **시간 무제한**입니다(MATCH_SECONDS=0). 브라우저 AI 검사는 매칭·무제한 표시·재접속·직접 나가기를 확인합니다. 별도 WebSocket 통합 테스트는 유한 시간 옵션으로 종료·재대결을 검사합니다. 점수·승패 강제 변경 API는 없습니다.

## 운영 빌드

```powershell
npm.cmd run build
npm.cmd start
```

`dist/`는 Netlify에 올리는 정적 사이트, `dist-server/`는 Node 서버입니다. `npm start`는 API/WebSocket 서버만 실행합니다. 프런트엔드 파일을 서비스하지 않습니다.

## 현 버전 범위

최초에는 카드 자료만으로 구현했으며, 이후 사용자가 제공한 C# 문법 판정기 전체를 포팅했습니다. 현재 대전은 `CheckPlayableSegment(sequence, false)`를 사용하고, 원본과 457,893회 비교해 불일치가 없었습니다. 탐험·상점·결제·광고·공개 랭킹은 포함하지 않습니다. 로컬 Node 서버는 메모리 저장이며, 공개 Cloudflare 서버는 SQLite Durable Object에 방·계정·세션을 저장합니다. 게스트 토큰을 잃거나 세션이 만료되면 임시 레이팅은 복원할 수 없습니다.

## 카드와 제출 (최신 규칙)

- 카드 60종(문법 카드 55종 + 기능 5종)을 각 1장씩 공유합니다. 원본 Very 2종은 덱에서 제외하고 사용자가 제공한 To부정사 기본형·+2·×2·÷2 네 장을 넣었습니다. 같은 그림 중복 지급·사용 카드 재순환은 없습니다.
- 20점 이하의 문법 정답은 0점으로 표시하며 필드·손패·점수를 유지합니다. 20점 초과 시 인정 구간만 사용 확정합니다. 점수 계산과 대표 예문 표시 후 고/스톱 선택으로 이어집니다. 사람이 선택할 때까지 자동 종료되지 않습니다.

### 카드 품사에 맞춘 예문 (v0.9.20)

기존 150개 예문 자료는 `shared/sentence-examples.ts`에 보존합니다. 실제 표시는 `shared/card-sentence-example.ts`에서 서버가 인정한 구간의 카드 순서/종류에 맞춰 생성합니다. 대명사·가산/불가산 명사·정관사/부정관사·소유격·BE/일반동사·DO/조동사·부정어·빈도부사/부사·전치사·형용사·To부정사를 구분하며, 주어에 맞춰 am/is/are, does/do, 일반동사 -s를 붙입니다. To 카드 한 장은 `to work`처럼 동사를 포함한 하나의 보어로 표시합니다. 각 표시 단어에 원본 카드 ID/종류가 연결되고, 인정 구간 밖 카드는 예문에 넣지 않습니다. 품사에 대응하는 설명 예문이며 카드 그림 속 특정 단어를 번역하는 기능은 아닙니다.

점수 계산이 끝나면 필드 위의 흰 패널에 영어·해석을 표시하고 자동으로 한 번 읽습니다. 재생 종료 이벤트 후 2초 기다린 뒤 닫히고 고/스톱으로 이어집니다. v0.9.23부터 TTS 오류·미지원·시작 실패는 사전 생성 음성으로 전환하며, 재생 자체가 막힌 경우에만 재시도 버튼을 표시합니다. 음성이 시작됐는데 종료 이벤트가 없는 경우 45초 안전 상한을 적용합니다. 이전 자동 읽기 OFF 설정은 더 이상 적용하지 않습니다.

사용자의 2026-10-13 결정에 따라 대전에 추가 표준 구조 검사를 적용합니다. 일반동사/조동사를 2형식 주격 보어로 사용한 조합, 부정관사+불가산명사, 명사 바로 앞 부사 단독 등은 오답 처리합니다. `JJ NNU`는 형용사+명사로 묶어 목적어가 하나면 3형식으로 바로잡습니다. 원본 Unity 판정 함수 자체와 원본 비교용 API는 유지합니다. 공유 판정이 서버와 AI에도 동일하게 적용되며 의미/시제까지 검증하는 기능은 아닙니다.
- 계산 영역에는 숫자만 표시합니다. 고 횟수에 따라 필드의 열기·불씨가 점점 강해집니다. 기존 카드는 JPEG 시트에서, To부정사 네 장은 `assets-source/ToInfinitive4.png`에서 분리해 lossless WebP로 렌더링합니다. 생성: `npm run cards:build`.
- 필드 카드 클릭/터치로 손패 복귀. 직접 드래그하면 원본 카드를 숨기고 삽입 위치를 미리 보여 줍니다.
- ROB 화면에는 다른 모든 참가자의 손패와 필드 카드를 한 목록으로 표시하고 카드마다 소유자 이름을 붙입니다. 카드를 고르면 대상 플레이어와 카드 위치가 자동으로 정해집니다. 경기 중 손패 앞면은 참가자들에게 공개되지만, ROB 선택 화면의 버전 조회 응답은 ROB 보유자에게만 전달됩니다. 서버가 카드의 위치와 버전을 다시 검사합니다. 필드에서 가져온 카드는 상대 필드·문장 미리보기·사용 카드 목록에서 없어지고 내 손패로 이동합니다. 이미 얻은 점수는 유지합니다. PROTECT는 상대 손패에 있으면 뺏기를 막습니다.
- EXCHANGE 요청 화면은 상대 프로필과 이름, 작은 제시 카드 미리보기를 표시합니다. 경기 중 선수 상태에는 마지막 기능 카드 행동과 득점한 문장들의 작은 카드 묶음이 표시됩니다. 문장 묶음이 많으면 가로로 스크롤할 수 있습니다.
- 20점 초과로 득점한 문장은 손패에서 사용 확정되지만 필드에는 다음 문장을 조합하기 전까지 계속 표시됩니다. 표시된 사용 확정 카드는 손패로 되돌릴 수 없습니다.
- 첫 화면에서 카드 얼굴 60종을 모두 다운로드하고 디코딩한 뒤 빠른시작을 표시합니다. 첫 접속은 네트워크에 따라 시간이 걸릴 수 있지만, 이후 카드는 브라우저 캐시를 활용합니다.
- 카드 배분 동의는 `0/2`처럼 현재 동의 인원으로 표시합니다. 전원 동의 시 30초를 기다리지 않고 배분한 뒤 타이머를 다시 시작합니다. 거절 버튼은 없습니다. 덱에 전원에게 줄 수 있는 카드가 부족하면 지급을 멈춥니다. 👍 👏 😮 🔥 감정표현은 선수 상태에 잠시 나타납니다.

## v0.9.14 규칙 및 관리자 진단

To부정사는 동사를 포함한 목적격 보어 카드이며 `대명사 + 일반동사 + 대명사 + To부정사` 네 장으로 5형식을 만듭니다. 별도 동사를 뒤에 붙일 필요가 없습니다. 명사/주격보어/부사 용법으로 To 카드를 득점하지 않습니다. 가장 긴 유효 연속 구간 규칙은 유지하므로 잘못 놓인 To가 제외되고 앞쪽 문장만 인정될 수 있습니다.

−2 인쇄 효과 카드 두 종은 운영 덱에서 제외했습니다(÷2는 유지). 기존 경기의 해당 손패/필드/남은 덱도 복구 시 정리하며 이미 얻은 점수는 유지합니다.

관리자 로그: https://logos-card-battle.netlify.app/admin. 접근 코드는 서버 Secret에만 설정되며 원본 저장소나 웹 번들에 넣지 않습니다. 요청·제출 결과·거절·연결 오류·클라이언트 조작을 최근7일/약5천개까지 수집합니다. 상세와 메모·상태·JSON 내보내기는 [ADMIN-LOGS.md](docs/ADMIN-LOGS.md)를 참고하세요.
