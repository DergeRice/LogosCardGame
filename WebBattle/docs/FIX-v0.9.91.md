# v0.9.91 — 2026-10-20 필수 상태만 체크포인트

## 변경과 복구 경계
- snapshot에서 nextAI/reaction/reactionAt/lastAction 및 room.log를 제외. AI 탐색 실패나 이모지 알림만 바뀌면 player/room 행을 다시 쓰지 않습니다. 기존 행도 다음 필수 커밋 때 같은 형식으로 전환합니다.
- restore에서 AI 탐색 예정 시각을 난이도의 thinkMs로 재생성하고 화면용 알림/로그는 비웁니다. 실제 카드·점수·재화·보호/교환·고 상태·버전·중복 방지 이력·접속 유예·배분/선택/경기 마감은 유지합니다. 재시작 후 AI는 새 생각 지연만큼 기다릴 수 있습니다.
- touchedAt는15분 올림. 실시간 메모리 값은 바꾸지 않고, 복구 후 게스트 만료만 최대15분 늦어질 수 있습니다. 30일 세션 보존을 일찍 종료하지 않습니다.
- Cloudflare CAPTURE_DIAGNOSTICS=0을 명시. 자동 로그·문장 통계 추가와 과거 통계 자동 backfill을 중지하며 기존 관리자 조회/메모/지급 및 기록은 유지합니다. 진단을 다시 켜더라도 저장 예외는 경기 처리로 전파하지 않습니다. 기존 하루1,000건 제한 코드는 보존합니다.
- 알람 스케줄 쓰기와 필수 상태 커밋은 남습니다. 진단을 끄더라도 필수 DB 한도 소진은 여전히 게임을 중단시킬 수 있습니다.
