# v0.9.75 설정과 게스트 이름

## 설정

UUID는 서버가 발급한 게스트 Player ID, 계정 연결 후에는 Account ID입니다. 로그인 토큰이나 비밀키를 표시하지 않습니다. 복사 버튼을 제공합니다. 이름이 바뀌거나 유효한 세션으로 새로고침해도 UUID가 유지됩니다.

계정 연동 영역은 Google/Apple의 준비 상태를 표시합니다. 운영 Wrangler secret 목록에는 소셜 인증 설정이 없었고 사용자도 아직 발급하지 않아 준비 화면까지만 요청했습니다. 실제 소셜 OAuth 로그인 검증을 완료했다고 보고하지 않습니다. 기존 Apple 계정은 서버가 보내는 provider로 연결됨을 표시하고 일반 계정은 별도 기존 계정 연결 상태로 표시합니다.

효과음은1~10 정수 단계로 저장하고 기존 원본 볼륨의10%~100%로 적용합니다. 클릭/승리 톤과 카드 배분/점수 파일 효과음이 같은 단계 함수를 사용합니다. 예문 음성 볼륨에는 적용하지 않습니다. 예문 보이기OFF는 이후 예문 패널과 자동 읽기를 끕니다. 켜진 예문을 수동으로 닫을 때 음성이 계속되는 동작은 유지합니다.

설정에서 검사 도구, 전체화면 버튼, 카드 확대, 치트, 나가기 버튼을 제거했습니다. 모바일 빠른 시작 시 자동 전체화면은 이전 사용자 요청에 따른 별도 진입 동작으로 유지합니다.

## 관리자와 프로필

/admin: 카드 뷰어·문장 음성 검사·프로필 크롭 도구·로그로 이동하는 페이지.
/admin/logs: 이전 로그와 통계/메모 관리 페이지. 기존 /admin#access=... 링크는 인증 정보를 처리한 뒤 /admin/logs로 경로를 정리해 새로고침에도 이어갑니다. 로그/메모 접근 정책은 기존 그대로이며 새로운 비공개 인증을 추가한 것이 아닙니다.

홈 치장 버튼은 제거했습니다. 프로필에 캐릭터·배경·프레임3개 태그를 두고 해당 보유품만 보여 줍니다. 장착과 기기 저장은 유지하며, 감정표현 재고를 삭제하지 않습니다.

## 이름

shared/guestNames.ts에125개 형용사구, 200종 동물 이름과 아기 표현을 합친400개 동물 표현을 사용해 정확히50,000개 이름을 만듭니다. 50,000개 전부 고유하고 숫자가 없으며 최대13자로 기존16자 제한에 들어갑니다. 서버는 읽기 쉬운 게스트 이름을 요청한 신규 연결에서 무작위 시작점을 택하고 사용 중인 이름이면 다음 후보로 이동합니다. 내부/기존 프로토콜의 명시적 닉네임 호출은 호환합니다.

기존 숫자 게스트는 같은 토큰으로 연결하면 이름만 바꾸고 rating/points/coins/Player ID를 유지합니다. 새 이름은 스냅샷 저장/복구 후에도 유지됩니다. 기기 치장 저장은 이전 이름의 저장 키를 새 이름으로 복사해 보존합니다. 동시 보관 이름은 피하지만 과거에 만료된 모든 역사적 이름을 영구 독점하는 정책은 아닙니다.

## 검증

- 단위/회귀162개 통과. 이름50,000개 전수 고유성·길이 검사, 충돌 후보 회피, 100개 서버 세션 중복 방지, 숫자 이름 전환 시 ID/토큰/점수 보존, 저장/복원, UUID와 계정 provider 메타데이터를 포함합니다.
- Chromium/WebKit 브라우저20개 통과, Windows WebKit Web Audio 미지원으로 음성2개 제외. 설정UUID/토큰 비노출/연동 준비·연동됨 표시,1~10 단계 저장, 예문 토글 저장, 치장3개 분류와 장착, 관리자 도구와 이전 접근 링크의 새로고침, 모바일 가로·세로 팝업/방 목록을 검사했습니다.
- Chromium에서 오디오 매개변수를 관측해 효과음1단계 .006 / 10단계 .06의 실제 톤 Gain을 확인했습니다. OFF 상태의 점수 연출 후 예문/자동 음성 미출력과 ON 상태에서 패널만 닫은 뒤 실제 Kokoro 재생 종료까지 검사했습니다. 점수 연출용 브라우저 상태는 UI fixture입니다.
- 실제 로컬 서버에 독립 브라우저2개를 연결해 서로 다른 형용사+동물 이름과 새로고침 후 동일 이름/UUID를 확인했습니다. 실물 Android/iPhone 검증은 별도입니다.
- TypeScript/Cloudflare 타입 검사와 운영 빌드를 확인하고 서버의 세션 응답 변경을 함께 배포합니다. 음원 파일은 변경하지 않았습니다.
