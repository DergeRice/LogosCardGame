# 고 주도권·피버·골드 (v0.9.63)

최초 인정 득점으로 최고점을 갱신한 사람이 고/스톱 선택권을 얻는다. 1고 선언 시 그 사람의 누적 점수가 기준점이 된다. 누구든 기준점을 **엄격히 초과**하면 다음 선택권을 얻는다. 같은 점수는 주도권을 바꾸지 않으며, 선언자도 자신의 기준점을 넘겨 다시 선택권을 얻을 수 있다. 고 횟수는 방 전체에서 공유한다.

| 단계 | 이후 새 문장 득점 | 최종 Elo 변화 | 승자 기본 골드 |
|---|---:|---:|---:|
| 0고 / 1고 | ×1 | ×1 | 300G |
| 2고 | 전원 ×2 | 전원 ×2 | 400G |
| 3고 | 전원 ×3 | 전원 ×3 | 500G |

이미 쌓인 점수를 소급해서 곱하지 않는다. 기본 카드 효과 뒤 피버 배수를 곱한 최종 문장 점수가 기존 기준인 20점을 초과하면 득점한다. 예를 들어 기본 13점 문장은 2고에서 26점으로 득점할 수 있다. AI에도 같은 판정 기준을 적용한다. 3고를 외친 순간에는 계속 진행하며, 이후 **누구의 다음 인정 득점이든** 반영한 뒤 종료한다. 그 사람이 3고 선언자의 점수를 넘지 않아도 종료하고, 최종 실제 누적 점수의 단독 최고점 플레이어가 이긴다. 무승부도 가능하다. 고/스톱·시간 종료·이탈 정산은 중복 보상을 지급하지 않는다.

Elo는 기존 상대별 기대승률 기반 변화량을 계산한 뒤 ×1/2/3을 적용한다. 감소량에도 같은 배수가 적용되고 레이팅 하한은 0이다. 코인과 별개인 기존 승리 포인트(P)는 상대 시작 레이팅 비율에 따른 300P 기준 보상이며, 이전의 개인 고 ×2 보상은 제거했다.

골드는 기존처럼 단독 승자에게만 지급한다. 무승부·패배·포기·치트 판은 0G다. 기본 골드에 다음 보정을 더하고 최종 보정 합계는 ±10% 안으로 제한한다. 서버가 시작 레이팅과 시작 시간을 보관하고 정산하며 계정/게스트 기록에 저장한다.

- 레이팅: 상대 평균 / 내 시작 레이팅 차이 ±10%를 -1~1로 정규화, 최대 ±4%.
- 점수: (내 최종 점수 - 60) / 120을 -1~1로 제한, 최대 ±2.5%.
- 시간: (경과 시간 - 180초) / 180초를 -1~1로 제한, 최대 ±1.5%.
- 매치: 쉬움 -2%, 보통 0%, 어려움 +2%. 사용자 방은 매치 보정 0%.

빠른 시작과 방 시작 전에 쉬움/보통/어려움을 선택한다. 빠른 시작 기본값은 보통이며 다른 난이도 선택자는 별도 매칭한다. 같은 난이도에서 사람 레이팅 주변 ±8%(편차 ±1%)를 기본으로 하고 쉬움은 ×0.85, 어려움은 ×1.15 레이팅을 적용한다. 실제 AI의 탐색량·행동 간격·고/스톱 판단에 선택한 난이도를 사용한다. 행동 간격은 9/6.5/4.2초다. 재대결에도 방 설정을 유지한다.

새 방은 규칙 버전 2로 저장한다. 서버 재시작 후 3고 대기 상태도 유지한다. 예전 버전에서 3고가 된 채 멈춘 방만 즉시 정산하는 복구 규칙을 유지한다. 마지막 덱 배분 뒤 5분 제한은 그대로다.
