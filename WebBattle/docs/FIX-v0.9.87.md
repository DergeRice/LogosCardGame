# v0.9.87

## 운영 데이터 추가
- 사용자의 요청으로 닉네임 ‘부지런한 아기땃쥐’, 기존 테스트 골드 지급 시 확인한 동일 플레이어 ID를 정확히 지정해 테스트 친구5명 추가.
- 테스트 나로 / 테스트 토리 / 테스트 보라 / 테스트 모리 / 테스트 루리. 모두 명시적으로 테스트 이름이며 오프라인. 실제 다른 이용자의 동의 없이 연결하지 않는다. 기존 친구/재화/레이팅을 변경하지 않는다. 오프라인이므로 방 초대용 온라인 선택 목록에는 나타나지 않는다.
- 관계는 양방향 CommunityRecord로 저장되며 단순 프런트 더미가 아니다. 일반 사용자 세션이나 로그인 토큰을 열람/대리 접속하지 않았다.
- /admin/grants/test-friends는 기존 마스터 관리자 Secret으로만 POST 허용. 브라우저/일반 WS로 호출할 수 없다. 정확한 대상1명 검사,100명 제한 선검사, 동일 grantId 재실행 및 고정 테스트 ID 중복 방지. 운영 계정에 재실행해 added0,total5 확인. 토큰은 .runtime에만 있고 Git/클라이언트에 포함하지 않는다.
- 운영 응답:200,added5,total5, 전원 online=false. 미인증401, 인증 GET405 확인. Cloudflare serial/persist 경로로 저장하고 연결 중인 대상에게 community 상태를 보낸다.
