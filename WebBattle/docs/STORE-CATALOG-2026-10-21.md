# 상자 카탈로그·확률 비교 — 2026-10-21

## 배경 압축파일

50개 중 파일 내용이 같은 20개를 제외하고 고유 배경 30개를 추가했다. 기존 이미지 10개와의 축소 RGB 비교에서도 일치 항목은 없었다. 원본 압축파일과 기존 보유 ID는 유지했다. 배경은 이미지 상품 40개 + 기본 배경 1개 = 총 41개.

## 원래 기획한 수와 현재 등록 수

비교 기준은 docs/STORE-VALUE-2026-10-20.md의 계획이다. 당시 배경 40개는 가정이고 보드판 40개는 상자 밖 교환 대상이었다. 포즈 이미지가 아니라 독립 아이템 ID를 센다. 기본/전용 상품을 제외한 실제 상자 후보 수도 구분했다.
