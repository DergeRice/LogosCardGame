# v0.9.94 선택 지급/보호막/전체 뒤집기

## 서버 규칙
- basicSupplyUsed를 플레이어와 RoomView에 저장. 기존 basicSupplyAt>0도 사용 완료로 간주합니다. 신규 수령은 덱 소진/진행 경기/선택 종류/요청ID/선택 대기/종료 시각을 확인하고 기본효과 없는 고유ID 카드1장을 지급합니다. 기본71장 공용 덱과 별도의 일회성 구조 카드이며 일반 재배분은 아닙니다.
- 대명사, 가산명사, 일반동사, 부정관사, 정관사, 전치사. AI도 동일 함수/1회 제한. 요청 중복은 ack만 재전송하고, 새ID로 반복해도 거절합니다. 재대결 reset에서만 사용 여부를 초기화합니다.
- 레이팅은 기존 Elo 평균 대결 결과(계수24)를 먼저 계산합니다. 음수만 loss=round(abs(delta)*1.5), score>=10이면ceil(loss/2). 같은 레이팅 완패는−18/−9. 정수 경계는 반올림 후 절반 올림으로 일관되게 처리합니다.
- 기존 초기2경기 배치 감점 보호, 승자 양수 변동, 최저0, 중복 정산 차단은 유지. 항복/이탈도10점 조건을 동일 적용합니다. 보호가 실제 음수 정산에 적용된 경우에만 ratingShield=true를 결과/복구/공개 프로필에 전달합니다.

## 화면
- 미수령자에게만6개 선택 버튼, 사용 후 배분 완료. 반복30초 보충 없음.
- 내 랭크에 보호막! / 레이팅 감소50% 표시. 프런트에서 감점 산식 재계산하지 않습니다.
- 전체 뒤집기1회. 일반 보상은 바로, 캐릭터/배경/프레임은0.85+(인덱스%10)*0.065초 후 공개. 실제 기다리는 동안만 DOM카드에 제한된 CSS 흔들림/색 변화, 타이머 언마운트 해제, reduced motion은 즉시 공개. 새 파티클/스프라이트를 추가하지 않고 기존 Pixi 상자 개봉을 유지합니다. 효과음은 첫10개만 제한합니다.
- 카드5열×2행 축소,10개 초과는 페이지. 전체 뒤집기는 해당 묶음 전체에 적용하며 페이지 이동/닫기는 지급을 발생시키지 않습니다. 무료 체험은 여전히 계정에 지급하지 않습니다.
- main의 storeResult 전달에서 source/box가 빠지던 경로도 고쳐 서버의 상자/직접 구매 구분을 유지합니다.
