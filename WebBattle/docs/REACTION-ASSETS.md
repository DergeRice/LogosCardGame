# 감정표현 이미지 교체

`public/reactions/`의 `thumbs-up.svg`, `clap.svg`, `wow.svg`, `fire.svg`는 현재 임시 이미지입니다.

`src/ReactionImage.tsx`의 `REACTION_IMAGES`에 PNG/WebP/SVG 경로를 넣으면 선택 버튼과 플레이어 말풍선에 함께 반영됩니다. 파일은 투명 배경 정사각형에 그림을 가운데 맞춰 준비하세요. 이미지가 로드되지 않으면 기존 이모지로 표시합니다. 전송 값은 기존 네 이모지를 유지하므로 서버 프로토콜을 바꿀 필요가 없습니다.

Google / Apple ID 버튼은 인증을 연결하지 않은 화면이며, 클릭 시 준비 중이라는 안내를 표시합니다. 게스트와 기존 아이디/비밀번호 계정은 그대로 이용할 수 있습니다.

연습모드 `/practice`는 활성 덱의 문법 품사마다 대표 카드 한 장을 제공하며, 반복 추가와 순서 변경이 가능합니다. 서버 매칭이나 점수·레이팅 저장 없이 배틀과 동일한 문법 판정과 카드에 맞는 예문을 사용합니다.

고는 문장 판정 점수에 공통 배율을 적용하지 않습니다. 한 번이라도 고를 외친 플레이어의 최종 획득 포인트만 2배이며, 다른 플레이어 보상과 레이팅 계산은 그대로입니다.
