# v0.9.92 상자 무료 연출 체험

사용자 목적은 잔액 없이 상자 연출을 보는 것입니다. 운영 게임 서버가 무료 DB 한도로 막힌 상태이므로 실제 가격/권위 지급은 보존하고 브라우저 전용 임시 무료 체험을 제공합니다.

- 실버1/10, 골드1/10, 다이아1/10/20/40/100회 버튼은무료 표시. 접속/잔액 검사를 체험에서만 생략합니다.
- 기존 공유 추첨기로 복제된 임시 지갑에서 보상을 만든 뒤 지갑 결과는 버립니다. 실제 계정·기기 보유품·재화에는 반영하지 않으며 storeOpen 메시지를 보내지 않습니다.
- 기존 StoreRewardModal/PixiLootBox를 재사용하므로 상자가 흔들리고 터진 후 한 장씩 뒤집습니다. 모달에 체험/차감·저장 없음 문구를 표시합니다.
- 별가루 직접 구매/장착/게임 서버/무료 플랜 최적화/분석 예약은 변경하지 않습니다. src/storePreview.ts의 FREE_BOX_PREVIEW=false로 정상 구매 UI와 요청이 돌아옵니다.

검증: npm test198건, npm run build. Chromium/WebKit의 PC1366×900과 모바일844×390(visualViewport330/top20)에서 서버 hello 응답 없이 세 상자 무료 개봉·카드 뒤집기·모달 위치·서버 구매 요청0·pageerror 없음 확인. 별도 직접 교환과10장 순차 뒤집기 회귀도 대상입니다. 브라우저 에뮬레이션이며 실물 휴대폰 검증이나 운영 계정 아이템 지급 검증이 아닙니다. 서버 변경이 없어 Cloudflare 재배포는 하지 않습니다.
