| 항목 | 수량 | 의미 |

| 분류된 문법 유형 | 72 | 형식 / 평서·의문·명령 / DO·MODAL·없음 / BE·VB / 긍정·부정 기준 |
| 검수용 대표 예문 초안 | 216 | 유형별 서로 다른 예문 3개, `example-review-candidates.json` |

고정 150개는 같은 기본 문장의 장소·방법·시간 수식 변형을 많이 포함합니다. 새 기준 72개 유형을 모두 커버하는지 별도 대조가 필요하므로, `216 - 150 = 66개만 추가`로 계산하지 않습니다. 자동 생성은 예문을 수십만 개 수작업으로 등록할 필요를 없애지만, 자연스러움과 한글 해석 검수까지 대체하지는 않습니다. 대표 216개를 우선 검수하는 것을 권장합니다. 이는 분류 기준에 따른 검수 계획이며 절대적인 영어 문법 유형의 총수가 아닙니다.

## 발견하고 수정한 누락

v0.9.51에서 독립적으로 구성한 기준 배열 7,749개 중 849개가 전체 인정되지 않았습니다.

| 누락 계열 | 기준 배열 수 | 예 |
|---|---:|---|
| 강조 DO 명령문 | 93 | Do work! / Do look happy! |
| BE 명령문 | 2 | Be happy! / Be near them! |
| 강조 DO + BE 명령문 | 10 | Do be happy! |
| 동사 앞 일반 부사 | 744 | I really work. |

그 외 전치사구를 가진 주어가 뒤에 보어를 갖는 BE 의문문을 예문 엔진이 잘못 분리하는 문제와, BE 뒤 NOT/부사를 거친 명사 보어 처리를 수정했습니다. 모든 발견 사항에 원래 Unity 기준 호출과 대전 확장 옵션을 구분합니다. 일반동사·조동사를 그대로 주격 보어로 쓰는 경우, 부정관사+불가산 명사, NOT 중복 등 이전에 오답으로 정한 조합은 예문 부재를 이유로 다시 허용하지 않습니다.

## 고유명사

`proper` ↔ `LearningPosType.PROPN`을 연결했습니다. 예문에서는 주어·목적어·보어·전치사 목적어 모두 **Naro / 나로**로 통일하며 3인칭 단수로 처리합니다. `Naro works.`, `Naro is happy.`, `Naro does not work.`를 확인했습니다. 음성 어휘도 Naro를 추가한 84개입니다.

현재 실물 공용 덱에는 고유명사 전용 카드가 없으므로 배분 카드 수와 구성은 그대로입니다. 고유명사 지원은 엔진과 확장 검사에 포함됩니다. 고유명사 앞에 일반 명사처럼 관사를 붙이는 표현은 별도 허용하지 않습니다. WH·CC 및 현재 빠져 있는 To/Very 카드의 실제 덱 투입도 이번 범위에 포함하지 않습니다.

## 한계와 재실행

- 15개 품사로 1~15장 모든 배열을 만들면 469,172,025,408,063,615가지입니다. 이는 틀린 배열까지 포함한 이론상 입력 수이며 정상 문장 수가 아닙니다.
- 6~15장은 정상 구조 생성 방식으로 검사했습니다. 모든 긴 배열, 모든 중첩, 카드별 실제 배분 가능성을 전수 검사한 것은 아닙니다.
- 어색한 의미, 전치사구의 해석 중의성, 두 빈도부사의 자연스러운 어휘 선택, 한글 번역 품질은 대표 예문의 사람 검수가 필요합니다. 품사 판정과 의미 검증을 혼동하지 않습니다.
- `npm run audit:examples`는 상세 통계와 검수 후보를 다시 생성합니다. 상세 결과는 `example-coverage.json`이며 실패 또는 음성 어휘 누락이 있으면 종료 코드 1입니다.
- 초기 v0.9.51 기준 세트는 7,749개였습니다. 현재 기준 세트는 새 부정·BE·형용사 연속 케이스를 추가했으므로 수량이 다릅니다. 과거 기준 측정값은 별도 필드로 보존합니다.
