# v0.9.86

## 변경
- surrender 메시지는 서버가 현재 battle/matchId를 검사한 뒤 finish로 정산하고 해당 플레이어를 결과 방에 유지한다. 기존 leave→home 경로에서 분리했다. 설정 확인 문구도 ‘항복하고 결과 보기’로 바꿨다.
- 항복/포기 등 forfeiter의 레이팅에는 초기3판 보호를 적용하지 않는다. 정상 경기 첫2판 보호/3판 집계 기준은 유지한다. 테스트 경기와0점 하한은 기존 규칙이다.
- RoomView.forfeiterId로 상대들이 동점이라 winner=null이어도 항복자는 패배로 표시한다. 해당 값은 저장/재접속에 남고 재대결 때 초기화한다. 결과의 두 버튼으로 재대결 또는 홈 이동한다. 동일 항복 재요청은 결과 phase라 거절되어 재정산하지 않는다.
- 프로필 장수는 PC9px/모바일8px, 카드 아이콘12px/10px(아주 짧은 화면9px). 닉네임의 기존 영역 안에서 중앙 정렬.
- 현재 drawVote.approved의 프로필은 초록 배경과 얇은 아웃라인. 마지막 미동의자가 나이면 기존 last-consent 조건에 밝기/테두리 맥동을 적용한다. 흔들기나 파티클은 추가하지 않았다. 동의 리셋 시 강조도 해제된다. reduced-motion에서는 고정 테두리로 표시한다.
- 보유 카드 텍스트 요약 정렬: ROB/EXCHANGE/PROTECT, multiply>1 또는 add>0, 동사/명사/대명사/관사/전치사 등 주요 품사, 나머지, Nothing. 같은 그룹은 기존 순서 유지. 요약만 정렬하고 손패 및 제출 문장의 실제 순서는 보존한다. Nothing의 기존 ‘꽝’ 텍스트 라벨을 변경했다.
