# 점수 효과음과 경기 종료 보강

v0.9.62 기록이다. 고 종료·배수·AI 난이도 규칙은 v0.9.63의 [현재 규칙](FEVER-RULES.md)으로 변경되었다.

- 효과음은 파일을 매 박자마다 새 Audio 요소로 재생하는 대신 미리 가져와 Web Audio 버퍼로 디코딩한다. 점수 단계의 절대 시각에 예약하며, 지난 박자를 뒤늦게 몰아 재생하지 않는다. 짧은 효과음 끝부분에 페이드를 적용하고 음성 예문과 같은 오디오 컨텍스트를 사용한다. 탭이 숨겨지거나 경기가 끝나면 예약한 점수 효과음을 취소한다.
- 2고는 계속 진행하고 3고는 즉시 정산한다. 사람과 AI에 같은 규칙을 적용하며, AI의 3고 점수 강제 보정을 제거했다. 저장된 방이 이미 3고인데 battle로 남아 있으면 다음 틱에서 정산하고, 결과 상태는 heartbeat 때도 재전송한다. 정산은 한 번만 실행한다.
- 결과가 도착하면 진행 중인 점수 계산·카드 선택·확대·설정 창을 닫아 결과 화면을 가리지 않게 한다.
- AI 스톱 확률은 정수 백분율로 계산한다. 0고 기본 30%, 1고 기본 48%에 난이도·점수 차이·남은 손패·덱 상태를 반영한다. 이미 2고인 AI가 다시 선택권을 얻으면 3고로 종료한다. 쉬움/보통/어려움 행동 간격은 9/6.5/4.2초이며, 975 미만은 쉬움, 975~1299는 보통, 1300 이상은 어려움이다. 실제 승률은 플레이 기록으로 추가 조정할 수 있다.

## 공용 덱 소진 후 기본 카드

공용 덱에서 전원에게 한 장씩 나눌 수 없으면 배분 영역을 대명사·셀 수 있는 명사·일반동사·부정관사·정관사 버튼으로 바꾼다. 선택한 기본형 카드 한 장을 새 식별자로 손패에 넣는다. 이는 소진된 물리 덱을 다시 섞는 기능이 아니며 점수 효과 카드를 복제하지 않는다.

한 사람이 하나를 받으면 다섯 버튼 전체에 30초 쿨타임을 적용한다. 다른 사람의 쿨타임과는 별개다. 진행 막대는 다섯 버튼에서 동시에 왼쪽에서 오른쪽으로 채워진다. 중복 요청·다른 카드 종류·쿨타임 우회는 서버에서 차단한다. AI도 같은 기능과 쿨타임을 사용하며 부족한 품사를 우선 선택한다. 마지막 배분 뒤 5분 제한은 그대로 유지한다.
