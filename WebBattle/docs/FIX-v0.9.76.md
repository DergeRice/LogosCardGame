# v0.9.76 — 필드 스와이프·상점·친구·6슬롯 대기실

## 조작 / 화면

- 터치로 바로 좌우 이동하면 가로 목록을 스와이프합니다. 약140ms 정지해 누르면 집기 상태로 전환하고 이동하면 순서를 바꿉니다. 짧은 탭은 손패 반환입니다. PC 직접 드래그·삽입 미리보기·쓰레기통은 유지합니다.
- 필드 진입의 확대 애니메이션을 제거해 조작 직후에도 미리보기 크기가 고정되게 했습니다. 기존 손패 배분 연출은 유지합니다.
- 허브·대기실·게임·결과의 문서 전체 스크롤을 잠그고 목록/상점/결과/모달 내부만 스크롤합니다. 작은 visualViewport와 offsetTop을 기준으로 화면 안에 배치합니다.
- 홈 문구는 ‘즐겁게 배우는 영문법’. 랭킹의 ‘함께 오르는 한 단계’는 제거했습니다.

## 상점

이전 로컬 체험 상점을 실제 서버 재화·인벤토리로 전환했습니다. 골드는 기존 대전 획득 골드입니다. 신규 서버 인벤토리는 기본 치장과 다이아0·별가루0에서 시작합니다. 이전 브라우저의 임의 체험 골드/다이아/치장을 실제 유료 인벤토리로 가져오지 않습니다. 기존 로컬 데이터는 삭제하지 않습니다.

|상자|1회|10회|20회|40회|100회|
|---|---:|---:|---:|---:|---:|
|실버|1,000골드|9,800골드|—|—|—|
|골드|3,000골드|28,000골드|—|—|—|
|다이아|100다이아|900다이아|1,700다이아|3,000다이아|6,000다이아|

|상자|별가루|캐릭터|배경|감정표현|프레임|
|---|---:|---:|---:|---:|---:|
|실버|35%|2%|10%|30%|23%|
|골드|30%|5%|15%|25%|25%|
|다이아|10%|15%|20%|25%|30%|

별가루는4~40개 균등 추첨, 중복 치장도4~40개 별가루로 전환합니다. 이는 정한 기본 규칙이며 중복 전환으로 최종 별가루 수령 비율은 표의 원래 별가루 추첨 확률보다 높을 수 있습니다. 종류 내 아이템은 균등합니다. 별가루100개로 미보유 치장 하나를 선택해 교환합니다.

서버의 암호학적 난수, 허용된 수량/가격, 소유권과 잔액으로 처리합니다. 클라이언트의 재화·추첨 결과를 받지 않습니다. 요청ID의 최근20개 결과를 재사용하며 거래 버전도 검사하므로 캐시가 지워진 옛 요청은 재차 차감되지 않습니다. 인벤토리·거래 버전·계정 골드를 SQLite 스냅샷에 저장합니다. 결과를 닫거나 하나씩 공개하지 않아도 획득품은 이미 저장돼 있습니다.

카드형 선물을 한 장씩 뒤집어 확인합니다. 모두 열기도 있습니다. 효과음은 기존1~10단계 설정을 따릅니다. 새 파티클/스프라이트를 만든 것이 아니라 접근 가능한 DOM 카드 버튼의 뒤집기 연출입니다.

다이아 상품:100개1,200원 /300개2,900원 /1,000개8,900원 /3,000개25,000원. 블록 그리드의 구매 버튼은 준비 안내를 엽니다. 결제 제공자·웹훅·현금 결제·다이아 지급은 연결하지 않았습니다.

## 친구 / 초대 / 대기실

- 결과 화면의 실제 인간 참가자에게 요청(상대가 먼저 홈으로 돌아가도 명단 유지) → 친구 탭의 받은 요청에서 수락 → 양쪽 친구에 등록됩니다. AI/자기 자신/같이 경기하지 않은 대상에 대한 요청은 거절합니다. 중복 요청,100명 친구/50개 받은 요청 제한을 적용합니다.
- 공개 UUID/계정ID로 저장하며 토큰은 친구에게 보내지 않습니다. 게스트는 세션 유지 범위, 로그인 계정은 계정ID로 이어집니다. 가입 시 게스트 친구 관계를 계정ID로 옮깁니다.
- 방장은6개 슬롯의 빈자리＋에서 중급 AI 또는 온라인 친구를 선택합니다. 친구 초대는2분 유효, 초대한 방의 상태·빈자리·초대 수신자를 서버에서 다시 확인합니다. 수락하면 같은 방에 입장합니다. 친구 관계와 만료 전 초대는 서버 재시작/휴면 복구 뒤에도 이어집니다.
- AI별 난이도 선택·×제거를 제공합니다. 개별 난이도가 경기 시작 시 공통 설정으로 덮이던 경로도 수정했습니다. 대기실은 허브와 같은 밝은 배경·그린 톤으로 맞췄습니다.
- 브라우저 연결이 있는 친구를 온라인으로 표시합니다. 다른 경기/방에 있는 친구는 초대 서버에서 거절하며 홈에 있을 때 입장할 수 있습니다.

## 리소스만 추가하기

`public/cosmetics/characters/`, `backgrounds/`, `emotes/`, `frames/`에 PNG/WebP/JPEG/SVG 파일을 넣습니다. 파일명이 표시 이름과 안정적인ID의 기준입니다(밑줄/하이픈은 이름에서 공백으로 표시). 배포 후 파일명을 바꾸면 새 상품으로 취급되므로 유지하세요. 기본 상품과 ID가 충돌하면 빌드를 실패시킵니다.

`npm run cosmetics:build`가 `shared/cosmetic-resources.ts`를 만듭니다. 운영 빌드와 Cloudflare 배포에서도 자동 실행합니다. 새 파일은 해당 종류의 동일 확률 풀·별가루 교환·서버 소유 목록·프로필 컬렉션에 등록됩니다. 캐릭터는 홈 메인 이미지, 배경은 홈 배경, 프레임은 홈/프로필 얼굴 위 투명 이미지입니다. 감정표현은 보유 시 게임 감정표현 선택에 추가되고 서버가 보유 여부를 검증합니다. 기존 대전용 네 캐릭터 얼굴과 홈 메인 캐릭터 장착은 서로 다른 설정입니다.

프레임은 가운데가 투명한 정사각 PNG/WebP, 캐릭터는 투명 배경, 배경은 가로 이미지, 감정표현은 정사각 이미지가 적합합니다. 새 실제 아트는 이번에 추가하지 않았고 기존 상자/캐릭터 리소스를 사용했습니다. 종류별 새 파일이 늘어도 해당 종류의 전체 확률은 유지하고 내부 균등 확률만 나눕니다.

## 검증

- 단위/회귀171개 통과: 상자별 확률 구간 전수, 가격/수량/별가루 경계, 재화 중복 차감 방지, 별가루 교환, 친구/초대 권한·수락·만료·저장 복원, 개별 AI 난이도, 리소스 자동 등록을 포함합니다.
- Chromium/Windows WebKit 브라우저38개 항목 확인. 초기 PC 드래그 검사에서2.3px 크기 차이를 발견해 필드 진입 확대를 제거하고 PC·모바일 드래그4개를 다시 통과했습니다. 최종 항목별 근거는 verification-v76.json.
- 서로 독립된 실제 두 브라우저를 로컬 서버에 연결해 방 생성/참가→자연스러운 제한시간 종료(테스트 서버2초 경기)→친구 요청/수락→초대/수락→같은 방→AI별 난이도/제거→새로고침 복귀를 Chromium/WebKit에서 확인했습니다. 점수나 승패를 강제 바꾸는 API를 쓰지 않았습니다. 운영 서버는 기존 무제한 경기입니다.
- 상점 브라우저 검사와 거래 WebSocket 검사는 테스트 잔액을 넣은 fixture입니다. 정상 경기에서 벌어 구매한 것으로 보고하지 않습니다. 거래 검사는 실제 로컬 WebSocket으로 같은 요청 두 개를 보내 한 번만 차감됨을 확인합니다. 현금 결제 검증은 없습니다.
- 모바일 가로/세로와 시스템 UI에 가려진 visualViewport, 내부 스크롤/문서 스크롤 잠금, Chromium 실제 터치 입력의 좌우 스와이프,140ms 집기와 재배치, PC 미리보기·버리기를 확인했습니다. 실물 Android/iPhone 검증은 하지 않았습니다.
- 음원/문법/경기 점수 규칙은 변경하지 않았습니다. 새 전체 예문/실물 음성 검증을 완료했다고 주장하지 않습니다.

### 추가 운영 검증

운영 Cloudflare의 서로 독립된 두 WebSocket 클라이언트가 공용 덱을 받아 실제6장 문장으로21점 득점했습니다. 중복 제출은 한 번만 적용됐고 정상 스톱으로 결과를 만든 뒤 친구 요청/수락, 온라인 초대/수락, 같은 방 입장, 개별AI 난이도/제거까지 오류0건으로 확인했습니다. 점수·재화 주입이 없습니다. 재현: `npx tsx scripts/verify-community-live.ts`. 이 명령은 실제 테스트 게스트 두 개를 생성하고 정상 경기를 플레이한 뒤 방을 정리합니다.

운영 모바일 화면에서 이전 room-panels.css의 높이/패딩이 새 대기실을 덮어 하단이28px 넘어가는 문제를 추가로 발견했습니다. 선택자 우선순위와 내부 그리드를 수정하고, 시스템 UI를 제외한330px 화면에서 상단/하단 경계와 버튼을 Chromium/WebKit 두 항목으로 재검사했습니다. 버튼은 고정하고 좌석 내용만 필요할 때 스크롤합니다. 최종 배포 화면도 같은 항목으로 확인합니다.
