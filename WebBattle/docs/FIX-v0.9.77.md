# v0.9.77

## 상점과 교환소

상자 세 종류를 한 줄씩 배치했습니다. 다이아 상품의1/10/20/40/100회 가격과 모든 기존 확률은 유지했습니다. 작은 화면에서 행의 오픈 버튼만 가로로 이동합니다. 별가루 교환소에는 캐릭터·배경·보드판·이모티콘·프레임5개 분류가 있습니다. 각 카테고리의 등록 상품 전체를 보여 주며 미보유는100별가루 구매, 보유는 장착하기, 선택 중인 상품은 장착 중으로 표시합니다. 구매와 장착은 서버의 잔액·소유권 검사를 통과해야 저장됩니다. 새 보상을 여러 개 공개할 때 결과 목록은 새 카드 쪽으로 이동합니다.

보드판은 기본 나무/정원 두 개의 기존 그림을 사용합니다. 내 대전 화면에만 적용하고 홈 배경과 분리합니다. 기본 보드는 기존 유저에도 기본 지급합니다. 감정표현 장착은 내 감정표현 열기 버튼에 반영되며 나머지 보유 감정표현도 기존 선택 목록에서 사용 가능합니다. 프레임·캐릭터·홈 배경 장착은 그대로 이어집니다.

보드판은 확률을 임의로 추가하지 않고 별가루 교환만 지원합니다. 자동 리소스 경로에 `public/cosmetics/boards/`를 추가했습니다. 다른 종류와 동일하게 파일 추가 후 프런트엔드 빌드와 Cloudflare 배포를 하면 자동 등록됩니다.

## 랭킹

서버 CommunityRecord에 정상 종료 판수를 영구 저장합니다.3판 미만은 랭킹 응답에 포함하지 않고, 첫2판은 레이팅 변화0이며 세 번째 정상 경기부터 기존 Elo 변화 계산을 적용합니다. 중복 정산은 한 번만 셉니다. 취소/경기 시작 전 종료/치트 판은 세지 않고 포기한 본인은 판수를 올리지 않습니다. 실제 진행된 경기에서 상대 포기로 정상 승리한 나머지 참가자는1판을 인정합니다. AI와 한 정상 경기도 포함합니다.

이전 버전에 누적 완료 횟수 필드가 없으므로 업데이트 이후 정상 종료부터 셉니다. 기존 점수는 유지하지만 집계 노출은 새 기록3판부터입니다. 계정ID에 연결된 기록은 재로그인/서버 저장 복원 후에도 유지됩니다. 더미 명단은 실제 화면에서 제거하고 해당 리그의 자격 있는 플레이어를 최대100명씩 서버에서 조회합니다. 홈/프로필/결과에도 배치 진행과 ‘3판 이후 집계됩니다.’를 표시합니다.

## 요청한 테스트 골드

‘부지런한 아기땃쥐’와 정확히 일치하는 기존 서버 세션1명을 찾아99,999,999골드 잔액으로 설정했습니다. 점수/레이팅/배치 판수는 변경하지 않았습니다. `/admin/grants/gold`는 서버 관리자 마스터 Bearer 인증과 POST가 필요하며, 공개 관리자 로그의 열람 권한이나 WebSocket 메시지로 지급할 수 없습니다. 인증 없는 운영 요청은401, 올바른 인증의 요청은200과 해당 이름/잔액을 반환했습니다. 요청ID를 저장해 같은 지급을 재시도해도 사용한 골드를 다시 채우지 않습니다. 비밀 토큰은 로컬 `.runtime/`에만 두고 소스/웹 번들에 포함하지 않습니다.

## 검증

- 단위/회귀176개 통과. 기존 레이팅 정산 검사는 배치 완료 fixture로 바꾸고, 첫 경기 재접속/유예 검사에는1000점 유지·판수1을 확인했습니다.
- 별도로 실제 두 WebSocket 클라이언트가 로컬 서버에서 짧은 제한시간의 정상 경기를3번 끝내고 첫2번에는 랭킹0명, 세 번째에 두 참가자만 집계되는 흐름을 확인했습니다. 점수나 판수를 주입하지 않았습니다.
- 단위 모델의 점수 fixture, 거래 잔액 fixture와 정상 WebSocket 경기는 구분합니다. 골드 지급은 사용자 요청에 따른 관리자 테스트 지급이며 정상 경기 획득 보상으로 보고하지 않습니다.
- Playwright Chromium/WebKit UI 12개 통과(기존 8개, 신규 4개). PC·모바일 가로/세로 및 작은 visualViewport를 검사했습니다. 신규 검사는 3개 상자 행 배치, 5개 교환 카테고리, 구매/장착/새로고침 유지, 0/3 미집계·3/3 집계, 보드판 실제 배경 연결, 문서 전체 스크롤 잠금을 확인합니다. UI 거래/배치 상태는 fixture이며 서버 거래·집계는 별도 테스트로 검사했습니다. 실물 휴대폰에서는 검증하지 않았습니다.
- 기존 문법·음원 파일은 변경하지 않았습니다. 현금 결제 연결도 이번 범위가 아닙니다.
