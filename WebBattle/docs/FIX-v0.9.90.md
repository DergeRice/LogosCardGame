# v0.9.90 — 사용자 제공 상자·티어 이미지 적용

- 실버/골드/다이아 상점 상자와 Pixi 개봉 및 CSS 대체 연출에 제공된 3종 이미지를 사용합니다. Pixi 상자 크기는 정사각형으로 맞춰 원본 비율을 유지합니다.
- 아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아 → 네더라이트 순서로 제공된 8종 배지를 연결했습니다.
- 홈 프로필, 리그 탐색/랭킹 행, 프로필 요약, 매칭·대전 소개 프로필, 결과 랭크에 같은 배지 컴포넌트를 사용합니다. 티어 이름과 숫자는 유지합니다.
- 이미지 11개는 모두 512×512 투명 WebP이며 합계 447,912바이트(원본 13,719,353바이트 대비 96.7% 감소)입니다. 시작 리소스 프리로드에 포함했습니다. 원본 다운로드 파일은 변경하지 않았습니다.
- 상자 가격·확률·보상 및 티어 판정 규칙은 변경하지 않았습니다.

검증: TypeScript/운영 빌드 성공. 기존 상자 구매·Pixi 개봉·개별 뒤집기 테스트가 Chromium/WebKit, PC/모바일 4개 조합에서 통과했습니다. 별도 화면 검증으로 8개 티어, 상자 3종, 프로필 이미지의 실제 512px 로딩과 브라우저 오류 없음을 확인했습니다. 모바일은 844×390 뷰포트에 visualViewport 844×330/상단 오프셋 20을 적용한 에뮬레이션이며 실제 휴대폰 검증은 하지 않았습니다.

결과 화면의 랭크·보상 연출·재시도·뷰포트 내 배치 회귀 테스트도 같은 브라우저/기기 크기 조합 4개에서 통과했습니다. 기존 브라우저 회귀 테스트 합계 8개 통과입니다.
