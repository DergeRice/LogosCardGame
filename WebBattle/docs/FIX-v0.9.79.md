# v0.9.79 — 대전 프로필 확대와 드래그 가장자리 이동

- 대전 참가자 프로필 그림 크기를 기존의 180%로 변경했습니다. 기본 36→64.8px, 1000px 이하 25→45px, 매우 낮은 가로 화면 20→36px, 해당 화면의 5~6인 18→32.4px입니다. 아바타는 참가자 행 전체 높이를 기준으로 세로 가운데에 두어 아래 품사 목록 때문에 위가 잘리지 않게 했습니다. 이름과 품사 목록의 시작 위치는 변경된 그림 크기를 따릅니다.
- 필드 카드 대신 안정적인 스크롤 컨테이너가 활성 드래그의 포인터를 잡습니다. 미리보기 슬롯을 옮기거나 원본 카드가 스크롤 밖으로 사라져도 캡처를 유지합니다. 필드 밖에서는 가장 가까운 삽입 위치를 계속 보여주며 손패 반환·쓰레기통 영역은 기존 우선순위를 유지합니다.
- 활성 드래그 중 화면 visualViewport 기준 좌우 20% 영역에 들어가면 필드가 해당 방향으로 자동 스크롤됩니다. 가장자리에 가까울수록 빨라지며 최대 650px/s, 프레임 시간은 40ms로 제한합니다. 매 프레임 현재 카드 위치로 삽입 위치를 갱신합니다. 손가락을 멈춰도 계속 이동하고 손을 떼거나 취소/Escape/창 비활성화 시 중단합니다. 카드가 모두 보이면 추가 스크롤은 발생하지 않습니다.
- 길게 누르기 140ms와 기본 좌우 스와이프, 손패 반환과 버리기를 유지했습니다. 같은 훅을 쓰는 연습 모드에도 가장자리 이동이 적용됩니다.

검증: 프로덕션 빌드·TypeScript 검사, Playwright Chromium/WebKit 관련 8개 시나리오 통과(드래그 미리보기/반환/버리기 4개, 스와이프/홀드 2개, 가장자리 이동 2개). 가장자리 검사는 모바일 가로 844×540, 실제 표시영역 844×480와 상단 20px 시스템 영역을 모의했습니다. 기존 스와이프 검사는 모바일 세로와 축소된 표시영역을 사용합니다. Chromium에서는 CDP 실제 터치 입력, WebKit에서는 합성 PointerEvent를 사용했습니다. 실물 휴대폰 검증은 하지 않았습니다. 서버 경기 규칙은 변경하지 않았습니다.
