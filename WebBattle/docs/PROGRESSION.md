# 로그인과 경기 보상

처음 접속한 탭은 로그인 화면만 표시한다. Google과 Apple ID는 업데이트 예정이며 인증 요청을 보내지 않는다. 게스트 버튼을 누른 뒤 서버 세션을 만들고 홈을 표시한다. 같은 브라우저의 게스트 토큰으로 포인트와 레이팅을 재사용한다. 서버 게스트 기록은 마지막 활동 후 30일 유지한다. 이 보관 기간은 경기 방의 마지막 배분 후 5분 만료와 별개이다.

300P는 승리했을 때의 기본 보상이다. 패배·무승부·포기는 0P이며, 특수카드 테스트 판은 보상이 없다.

기본 보상 = 반올림(300 × 상대들의 경기 시작 전 평균 레이팅 / 내 경기 시작 전 레이팅).

1000 레이팅에서 상대 평균 900 / 950 / 1000 / 1050 / 1100이면 승리 시 270 / 285 / 300 / 315 / 330P이다. 개인 고에 따른 포인트 2배는 제거했다. 2고/3고는 이후 새 문장 점수와 최종 레이팅 변화에 전원 ×2/×3을 적용한다. 골드는 별도이며 1고 300G, 2고 400G, 3고 500G 기준에서 시간·점수·레이팅·매치 보정을 합쳐 ±10% 내로 지급한다. 정산은 한 경기당 한 번만 수행한다. [현재 고·피버·골드 규칙](FEVER-RULES.md).

사람끼리는 약 10% 이내 레이팅 범위에서 매칭한다(최저 허용 차이 50). 빠른 시작 아래와 사용자 방에서 AI 난이도를 선택한다. 기본은 보통이며 난이도별로 매칭한다. 같은 난이도 안에서 사람 레이팅에 맞춰 AI 레이팅을 분포시키고, 선택한 난이도를 실제 탐색량·행동 간격·고/스톱 판단에 적용한다.

통화나 앱 전환으로 연결이 끊겨도 180초 안에 돌아오면 같은 손패와 경기로 복귀한다. 고/스톱 선택 중 화면이 멈추면 45초 뒤 현재 점수로 자동 스톱한다. 경기 시작 전 연결이 끊겨 취소되거나 모든 사람이 이탈한 경기는 포인트와 레이팅을 바꾸지 않는다. 대전 중 180초를 넘긴 이탈은 패배로 정산하며, 결과는 30분간 보관한다. 마지막 5분 종료 결과도 이 기간 동안 확인할 수 있다.

To부정사 기본형·+2·×2·÷2 네 장은 현재 덱에서 일시 제외한다. 복구된 진행 중 경기의 손패·필드·남은 덱에서도 제거하되 이미 획득한 점수는 유지한다. 카드 원본과 문법 판정 코드는 나중에 다시 넣을 수 있도록 보존한다.

## 음성과 연습 설명 봇 계획

5만 문장을 한 목소리로 사전 생성할 수 있다. 요청 큐, 실패 재시도, 완료 파일 목록, 문장 텍스트 해시를 사용하면 잔액이나 실행 중단 후에도 이어서 생성할 수 있다. 현재 단계에서는 유료 API를 연결하거나 대량 음성을 생성하지 않았다.

연습 설명은 먼저 판정기의 실패 위치·예상 품사·인정 구간을 구조화하고 규칙별 설명과 수정 예시를 제공하는 방식이 적합하다. 가능한 문장을 판정기 누락 때문에 틀렸다고 설명하지 않도록 지원 문법부터 점검해야 한다. 자유 질문과 자세한 설명이 필요할 때 검증된 판정 정보를 외부 AI에 전달하는 혼합 방식을 추가한다.
