# 카드 에셋

## 출처와 권한

사용자가 다운로드 폴더의 카드 이미지 활용을 직접 요청했습니다. 오늘 받은 `drive-download-20260927T055135Z-1-001.zip`에서 다음 파일 5개를 확인했습니다. ZIP에는 별도의 라이선스/저작권 문서가 없습니다.

| 파일 | 확인한 내용 |
|---|---|
| CardImage1.jpg | 대명사·불가산명사 |
| CardImage2.jpg | 가산명사·관사 |
| CardImage3.jpg | 일반동사·Be동사 |
| CardImage4.jpg | Do·소유격·전치사·특수 행동 카드 |
| CardImage5.jpg | 조동사·not·빈도부사·형용사·부사·Very |

사용자 제공 자료로 로컬 구현에 사용했습니다. **웹 공개 배포/상업 이용 권한이 확인되었다는 뜻은 아닙니다.** 공개 배포 전 소유권 또는 이용허락 확인이 필요합니다. 별도의 Unity 에셋이나 인터넷 이미지는 사용하지 않았습니다.

## 표시 방식

- 원본을 `assets-source/`에 보존하고, 웹용 동일 파일을 `public/assets/`에 복사했습니다. 사용자 다운로드 원본은 수정하지 않았습니다.
- 각 시트는 2086 × 2225 JPEG이며 4열 3행입니다.
- 사용자 후속 요청에 따라 `src/theme.ts`의 좌표로 시트에서 카드 전체(488 × 693)를 표시합니다. 테두리·제목·삽화·숫자·설명을 모두 보존하며 이미지와 텍스트를 재생성하거나 편집하지 않습니다.
- 손패·문장 조합 영역·첫 화면 모두 원본 카드 디자인입니다. 손패는 원호에 겹쳐 배치하고, 필드 카드는 손패에서 숨깁니다. 필요하면 손패 펼쳐 보기로 좌우 스크롤할 수 있습니다. 상단 번호·별과 달리 인쇄된 ×/+ 점수 효과는 해당 그림의 VARIANTS와 연결되어 실제 점수에 적용됩니다. 효과 없는 그림에 효과를 임의로 부여하지 않습니다.
- 5장의 전체 시트 합계 약 6.6MB. 브라우저 캐시를 재사용합니다. 향후 그림만 별도 AVIF/WebP로 내보내면 다운로드량을 줄일 수 있습니다.
- 카드 선택 위치는 `shared/rules.ts`의 CATALOG, 시트와 크롭 영역은 `src/theme.ts`에서 변경합니다.
- 효과음은 Web Audio oscillator로 짧게 합성합니다. 음원 파일 라이선스가 필요하지 않으며 상단 ♪로 끌 수 있습니다.
- 폰트는 Google Fonts Noto Sans KR, 실패 시 운영체제 sans-serif로 대체됩니다. SIL OFL 1.1입니다. [Noto 폰트 라이선스](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)

- 임시 프로필은 같은 카드 속 캐릭터를 원형으로 확대 표시합니다. 원본 이미지를 수정하지 않으며 프로필 표시 위치는 src/quick-battle.css의 character-avatar 규칙으로 조정합니다. VS 등장/중앙 덱 배분도 CSS 애니메이션입니다.
