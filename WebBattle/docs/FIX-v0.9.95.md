# v0.9.95 — 프레임 30종 / 보상 이름 숨김 / 상자 경제 분석

- 제공된 프레임 30종을 512×512 투명 WebP로 최적화하여 기존 상자 풀/100별가루 교환소에 등록했습니다. 기존 3종은 보존하여 전체 프레임은33종입니다. 상자 종류 확률과 가격은 변경하지 않았습니다.
- 상점과 보관함 프레임 이름을 화면에서 숨기고 장착/구매 버튼은 유지합니다. 상자 결과는 모든 상품 이름을 숨기며 별가루 수량·중복 보상·새 치장 여부는 표시합니다. 직접 구매 결과에서는 프레임 이름만 숨깁니다. 접근성 설명과 내부 ID는 보존합니다.
- 상점/보관함/보상 미리보기는 캐릭터와 투명 프레임을 겹쳐 보여 줍니다. 장착 프레임은 홈/프로필뿐 아니라 대기방·매칭·대전 점수판·결과의 참가자 프로필에도 보입니다. 서버 공개 참가자 데이터에 선택한 frameId를 추가했으며 이전 클라이언트/저장 데이터와 호환되는 선택 필드입니다.
- 현재 무료 상자 연출 체험은 유지합니다. 시뮬레이션을 실제 유료 결제·운영 DB 쓰기·보상 지급으로 실행하지 않았습니다.
- [상자 경제 분석](STORE-ECONOMY-2026-10-20.md): 실제 생산 추첨 함수, 시드 고정, 상자별 각10,000회 신규/연속/수집완료 시나리오 및 첫100별가루 도달 실험. [재현 스크립트](../scripts/simulate-store-economy.ts)와 원본 JSON을 포함합니다. 설정된 다이아 가격의 원화 배분 비용과 가정에 의존하는 골드 참고 환산을 구별합니다.

검증: 운영 빌드/TypeScript, 신규 프레임 교환·장착·중복 결제 방지·상대 공개·재시작 복원 테스트2개, 실제 Miniflare 4인 WebSocket 경기/재시작 복구/진단 저장 비활성 검증 통과. 모든30개 파일의512px 크기·투명 중앙을 확인했습니다. Chromium/WebKit PC와 모바일844×390(visualViewport844×330, top20)에서 프레임 표시/장착/이름 숨김 및 무료 상자 연출8개, 대전 프레임 중심 정렬/항복 결과4개 등 브라우저 테스트12개가 통과했습니다. 실제 휴대폰 검증은 하지 않았습니다.
