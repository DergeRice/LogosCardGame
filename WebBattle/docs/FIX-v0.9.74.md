# v0.9.74 플로팅 홈

홈 전체에 기존 장착 배경을 적용하고 그 위에 UI를 분리해 띄웁니다. 방 목록은 PC에서 기본 표시합니다. 폭1023px 이하 또는 주 입력이 터치인 화면에서는 방 목록을 버튼을 누를 때만 모달로 마운트합니다. 초기 접속/탭 복귀/PC에서 모바일 크기로 변경할 때 자동으로 방 창을 열지 않습니다. 방 데이터 갱신은 기존15초 주기를 유지하며 데이터 수신 자체는 팝업을 열지 않습니다.

모바일 가로는 캐릭터와 조작을 나란히 배치해 캐릭터가 작은 위쪽 칸에 갇히지 않게 했습니다. 세로는 중앙 캐릭터와 하단 조작을 사용합니다. 홈 버튼, 프로필, 재화, 탭은 배경이 비치는 플로팅 패널입니다. 다른 탭의 화면은 기존 배치를 유지합니다.

캐릭터 기본 그림과 빈 의상/액세서리 레이어를 같은 스테이지에 분리했습니다. 향후 캐릭터와 맞는 분리 에셋을 얹을 수 있는 구조입니다. 현재 캐릭터 두 명이 그려진 원본을 개별 캐릭터 의상으로 분해한 것은 아니며, 새 의상/장착 상품을 구현했다고 보고하지 않습니다. 캐릭터 치장 버튼은 현재 보유 컬렉션으로 이동합니다.

검증: Chromium/WebKit 각각 PC 허브·터치 가로·터치 세로·방 목록 닫기/탭 복귀·페이지 넘김·튜토리얼·상점·실제 두 세션 방 생성/참가/방장 이전/시작을 포함한16개 브라우저 검사 통과. 모바일 검사는 visualViewport 높이를60px 줄이고 offsetTop20px인 상황을 포함합니다. 문서 전체 가로/세로 스크롤이 생기지 않는지와 방 모달 경계를 검사하고 스크린샷을 확인했습니다. 실물 휴대폰 검증은 별도입니다.

서버/공유 경기 규칙/음원 파일은 변경하지 않았습니다. 공개 클라이언트는 v0.9.74이며 같은 web-battle 브랜치의 Netlify 배포를 사용합니다.
