# 관리자 진단 로그

운영 페이지: https://logos-card-battle.netlify.app/admin

접근 코드는 Cloudflare `ADMIN_LOG_TOKEN` Secret입니다. 프런트엔드·GitHub에 넣지 않습니다. 이 PC의 `.runtime/admin-access.txt`에 초기 코드와 URL을 저장했습니다. 브라우저에는 로그인한 페이지 메모리에서만 유지하며 잠그기/새로고침 시 다시 입력합니다. 게임 계정 로그인과 별도 권한입니다.

## 보기 및 수정 작업

- 닉네임·방번호·요청 ID·오류 문구로 검색하고 행동/거절/오류, 처리 상태로 필터링합니다.
- 항목을 누르면 요청 카드, 서버 손패 버전, 경기 단계, 행동 대기 시간, 고/스톱 상태, 판정 점수/구간과 클라이언트 UI 상태를 확인합니다.
- 같은 요청 ID를 검색해 요청→거절/판정→재시도 흐름을 함께 봅니다.
- 미확인/확인 중/해결 상태와 재현 메모를 저장합니다. 경기 상태나 점수를 직접 바꾸는 기능은 아닙니다.
- 검색 조건 전체를 JSON으로 저장해 이 채팅의 수정 요청에 첨부할 수 있습니다. 실제 게임 코드 수정은 검토·테스트 후 GitHub/Netlify/Cloudflare로 배포합니다.

## 기록 종류와 보관

서버가 받은 제출·카드 배분·특수카드·교환·고/스톱·감정표현·로그인 등의 요청, 제출 판정/득점 여부, 거절 사유, 연결/재접속, 서버 오류를 기록합니다. 클라이언트는 선택/반환/순서 변경/모두 되돌리기/특수카드 선택/프로필 보기와 제출 시도·차단·응답 시간초과·브라우저 오류를 기록합니다. 드래그 좌표 매 프레임은 기록하지 않고 완료 행동을 모아 보냅니다. UI 기록은 클라이언트 보고이며 서버 사실과 구분합니다.

로그는 기존 SQLite Durable Object의 별도 `audit_logs` 테이블에 저장해 서버 재시작 후에도 유지합니다. 최근 7일, 약5천개로 자동 정리하며 연결 요청 제한과 UI 기록 전송 간격을 적용합니다. 설정이나 유료 서비스를 새로 추가하지 않습니다. 비밀번호·세션/계정 토큰·관리자 접근 코드·원본 요청 객체·IP 주소는 기록하지 않습니다. 클라이언트 문자열에 토큰처럼 보이는 값이 들어가면 가립니다.

지금 배포 이후부터 수집합니다. 과거 제보 당시의 로그는 복원할 수 없습니다. 오프라인 상태나 저장 한도/장애 동안의 기록은 누락될 수 있습니다. 로컬 Node 서버의 테스트 기록은 메모리이며 운영 관리자 페이지는 Cloudflare 저장 로그를 조회합니다.

## 접근 코드 교체 / 로컬 Cloudflare

`npx wrangler secret put ADMIN_LOG_TOKEN`으로 새 코드(최소24자, 충분히 긴 무작위 값)를 서버에 입력합니다. 값을 netlify.toml, VITE 환경변수, 공개 문서에 적지 마세요. 로컬 Cloudflare 테스트에서는 Git 제외된 `.dev.vars`에 같은 이름을 설정합니다. 접근 코드/Origin 검증 없이 로그를 공개하지 않습니다.

## 제출 거절을 읽는 기준

- `이전 카드 상태`: GET·ROB·교환·배분 등으로 handVersion이 바뀌었습니다. 최신 상태를 받아 재시도합니다.
- `pending`, `score_animation`, `cooldown`, `go_decision`, `opponent_preview`, `empty_field`: 클라이언트 제출 버튼이 막힌 상태입니다.
- `valid_below_threshold`: 문법은 맞지만 문장 점수가20 이하라 필드를 유지하고 득점하지 않은 정상 규칙입니다.
- `invalid_grammar`: 가장 긴 유효 구간에도 문장으로 인정할 카드가 없습니다.
- `SUBMIT_TIMEOUT`: 6초 안에 ACK/관련 판정 상태를 받지 못했습니다. 요청 ID·연결 기록·서버 결과를 함께 확인합니다.

이번 보완은 실패한 요청 ID를 성공으로 오인해 ACK만 돌려주던 처리, 무관한 ACK로 제출 대기가 풀리던 처리, 전송 실패 후 대기만 시작하던 처리 및 오래된 손패 재동기화를 수정합니다. 기존 제보의 정확한 재현 조건은 아직 없으므로 신규 로그로 후속 원인을 추적합니다.
