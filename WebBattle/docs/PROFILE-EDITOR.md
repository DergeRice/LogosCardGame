# 프로필 작업실 (이 PC 전용)

주소: http://127.0.0.1:5174

`npm run profile-editor`로 실행하거나 `Start-ProfileEditor.ps1`을 PowerShell에서 실행합니다. 게임 서버는 Cloudflare에 있으며 이 편집기는 게임 서버가 아닙니다. 편집기를 꺼도 대전은 계속됩니다.

1. 캐릭터 선택. 기존 저장 이미지를 불러오며 **원본 카드로 초기화**를 누르면 원본 카드 시트에서 다시 자를 수 있습니다.
2. 드래그로 위치, 확대 슬라이더로 크기 조절. 별도 JPG/PNG/WebP 이미지도 불러올 수 있습니다.
3. **크롭 저장**: `public/profiles/<kind>.png` (512×512)와 `manifest.json`을 이 PC에 저장합니다. PNG 다운로드도 가능합니다.
4. **저장한 프로필 게임에 반영**: 현재 프런트 소스를 빌드해 연결된 Netlify 사이트에 배포합니다. 성공 표시 후 게임을 새로고침합니다. 이 PC의 Netlify CLI 인증과 인터넷 연결이 필요합니다.

저장한 프로필은 매칭, 대기, 점수판의 캐릭터 이미지에 공통으로 사용합니다. 모든 플레이어가 같은 캐릭터 프로필 세트를 봅니다. 현재 8개 초기 크롭이 포함되어 있습니다.

편집 HTML/API는 인터넷 배포물에 포함되지 않습니다. 서버는 127.0.0.1만 수신하고 Host/Origin을 확인하며 외부 Origin 저장/배포 요청을 거절합니다. 같은 PC를 사용하는 다른 OS 사용자까지 구분하는 로그인 시스템은 아닙니다.

## 카드 지급

손패 장수 제한은 없습니다. 현재 총 34장 단일 덱은 소진 후 재생성하지 않습니다. 따라서 정상 2인 균등 지급만으로는 한 명에게 20장이 넘어가지는 않습니다. 20장 초과 보유는 별도 제어 테스트에서 확인했습니다. 문법 검사/한 번 제출 영역의 15장 한도와 손패 수량은 별개입니다.

수령 연출은 `src/useDealtHand.ts`, `src/game-stage.css`에서 조절합니다. 지급 간격 220ms, 상승 560ms. 이미 소유한 카드를 필드에서 돌려받거나 경기 도중 새로고침해 복귀하면 수령 연출을 반복하지 않습니다. 서버 손패가 최종 기준입니다.

## 카드에서 바로 가져오기와 위치 조절

편집기를 새로고침한 뒤 **+** 버튼을 누르면 현재 카드 39종에서 선택할 수 있습니다. 선택한 이미지는 현재 프로필 슬롯에 불러오며, 마우스 드래그/한 손가락 터치로 밀어 위치를 맞추고 슬라이더·휠로 확대합니다. **크롭 저장** 전에는 기존 파일이 변경되지 않습니다. **PNG 다운로드**로 별도 파일을 받을 수도 있습니다.
