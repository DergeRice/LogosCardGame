# v0.9.100 — 점박이 감정표현10종

사용자 제공 PNG10장을 원본 그림과 투명도를 유지한 채512×512 lossless WebP로 변환했다. 그림을480×480 안에 비율 유지해 배치하고16px 여백을 넣었다. 파일 합계1,840,992바이트이며 원본 Downloads는 변경하지 않았다.

- 점박이 인사·응원·화남·놀람·고민·눈물·사랑·부끄러움·하품·최고.
- 기존34종 + 새10종 = 총44종. 상자 감정표현 풀에 새10종을 추가하고, 별가루200 교환/중복15 및4칸 장착/경기 반영 경로를 사용한다. 기존6종 무료 지급과 상자 카테고리 확률은 변경하지 않는다.
- 상품ID와 이미지 주소는 자동 생성 카탈로그로 클라이언트와 서버가 공유한다. 시작 시 새10종도 미리 다운로드·디코딩한다.
- `scripts/import-spotted-emotes.mjs [원본 폴더]`로 재현한다. 파일 이름은 안정적인 상품ID이므로 출시 후 유지한다.

## 검증 범위

전체 감정표현 추가 이미지30개에 대해512px/투명 모서리/사전 로딩/실제 추첨 가능 여부를 검사한다. 로컬 실제 WebSocket2개로 점박이 인사를200별가루 구매→장착→상대에게 전송하는 경로를 검사하며, 잔액은 테스트용 시드다. 운영 사용자의 재화를 수정하지 않는다.

UI 검증은 Chromium/WebKit의 PC 및 모바일 가로(visualViewport330px)에서 상점44종, 추가 이미지30개, 점박이 포함4칸 장착, 인게임 점박이 전송을 검사한다. UI 서버 상태는 모의 응답으로 실제 구매 성공과 구분하며 실제 휴대폰 검증은 아니다. 운영 배포 후 이미지 실제 HTTP/디코딩/해시와 모바일 UI를 별도로 검사한다.
