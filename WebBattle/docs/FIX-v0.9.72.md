## 동일 Kokoro 대체 경로

정적 MP3 → R2 MP3 → Kokoro.js1.2.1 / af_heart / q8 WASM의 문장 전체 추론 순서입니다. 새로운 미녹음 문장을 무음으로 끝내거나 기기 기본 음성으로 바꾸지 않습니다. 다만 최초 누락 문장은 모델92,361,116바이트와 런타임 다운로드가 필요하고, 기기 성능/네트워크/오디오 권한 실패까지 성공으로 보장하는 것은 아닙니다. 실패는 기존 진단 로그에 남기며 게임 입력을 막지 않습니다. 오래된 요청의 뒤늦은 응답은 생성 대기열에 들어가지 않도록 취소합니다.

## 실행 검증

- 기본/회귀 테스트155개 통과, 실패0개. 새로운 검사에는 새39,143개 key/remote 메타데이터 대조, 최신847개 조합 연결, 전체 고정 후보 누락0 검사가 포함됩니다.
- TypeScript, Cloudflare 타입 검사, 운영 빌드 통과. 메인 게임 서버 규칙 변경은 없으므로 게임 서버는 재배포하지 않았습니다.
- 운영 정적 manifest 내용 일치, 신규 정적8개 HTTP200/audio MIME/바이트/SHA-256 일치. 로컬 정적1,089개 전부 해시 일치.
- 운영 무작위20문장+회귀/제보15문장, PC Chromium과 Android Chrome 터치 모사 각35회, 총70회 실제 비무음 AudioBufferSource 시작·종료 확인. HTTP200만으로 통과 처리하지 않았습니다.
- 별도 빌드 브라우저 검사3개 통과: PC/모바일의 실제 WASM 생성·재생·캐시와 늦은 응답 역전, 생성 정지 fixture에서도 고/스톱·다음 카드 입력 유지. fixture의 점수/상태는 정상 플레이나 실제 음성 재생 증거로 합산하지 않았습니다.
- 초기 운영 연속 요청 검사에서 모바일 실패1건을 발견했습니다. 취소된 예문 응답이 최신 대기 작업을 밀어내는 문제였으며, 취소 확인과 녹음 전용 사전 로딩으로 수정한 뒤 같은 역전 조건의 PC/모바일 검사 모두 통과했습니다.
- 실제 Android/iPhone 스피커 검증은 하지 않았습니다. Windows WebKit의 Web Audio 미지원도 실기기 Safari 검증으로 부르지 않습니다.
