# v0.9.73 홈 / 리그 / 상점

## 구현

하단에는 요청에 나온 다섯 이름을 기준으로 홈, 랭킹, 친구, 상점, 프로필을 배치했습니다. 홈에 실제 공개 대기방이 바로 표시되며3개씩 좌우로 넘깁니다. 방이 없으면 빈 목록을 보여 주고 실제 방을 만들 수 있습니다. 기존 빠른 시작의 매칭 규칙은 유지합니다.

홈 캐릭터와 배경은 기존 로고스 에셋을 재사용합니다. 상자 이미지는 새 SVG 임시 이미지입니다. 외부 유료 에셋/결제는 사용하지 않았습니다. 배경, 메인 캐릭터, 프레임은 보유 컬렉션에서 선택해 바로 홈에 적용됩니다. 감정표현은 보유 목록까지 구현했으며 대전용 감정표현 장착 연결은 후속 범위입니다.

## 리그

현재 레이팅 숫자를 리그로 변환하는 표시 계층입니다. 실제 승패에 따른 기존 레이팅 증감 규칙과 신규1000점을 변경하거나 기존 계정을 초기화하지 않습니다.

| 리그 | 5단계 시작점 | 1단계 시작점 |
|---|---:|---:|
| 아이언 | 300 (399점까지, 300이하 포함) | 700 |
| 브론즈 | 800 | 1200 |
| 실버 | 1300 | 1700 |
| 골드 | 1800 | 2200 |
| 플래티넘 | 2300 | 2700 |
| 에메랄드 | 2800 | 3200 |
| 다이아 | 3300 | 3700 |
| 네더라이트 | 3800 | 4200 이상 |

각 점수는 해당 구간의 하한입니다. 따라서 브론즈3은1000~1099, 브론즈4는900~999입니다. 랭킹은 현재 리그에 해당하는 더미12명과 나를 점수 순으로 표시합니다. 실제 전역 랭킹 API나 친구 계정 검색을 완성한 것으로 보고하지 않습니다.

## 체험 상점

- 실버1000G, 골드3000G, 다이아100◇를 임시 가격으로 사용하고10회는10배 가격입니다.
- 실제 서버 골드와 별도인 체험 골드50000G/체험 다이아1000◇로 시작합니다. 체험 충전 버튼으로 복원할 수 있습니다. 실제 대전 재화나 현금 결제와 연결하지 않습니다.
- 기본 확률은 별가루35%, 캐릭터15%, 배경15%, 감정표현20%, 프레임15%입니다. 중복 치장은 별가루25개로 변환하므로 보유품이 많으면 최종 재화 결과 비율은35%보다 높아질 수 있습니다.
- 세 상자의 기본 카테고리 확률은 현재 동일합니다. 등급 차이·정식 가격·중복 규칙·출시용 에셋 풀은 기획 확정이 필요합니다.
- 구매 횟수/부족한 체험 잔액을 검증합니다. 별도 로컬 시제품이며 실제 보유 재화를 클라이언트가 변경하는 운영 상점으로 사용하면 안 됩니다. 정식 출시에는 서버 구매·보유·중복요청 검증이 필요합니다.
- 캐릭터/배경/프레임 장착·체험 소유품은 기기 저장소에 보관합니다. 브라우저 데이터를 삭제하면 초기화됩니다. 얼굴 프로필은 서버가 허용한4개만 변경하고 계정에 저장합니다.

## 예문과 음성

예문 패널을 다시 누르면 바로 닫히지만 재생 객체는 끝까지 유지합니다. 종료 후 원래처럼2초 뒤 자동으로 닫히는 흐름도 유지합니다. 이전 패널의 종료 콜백이 다음 패널을 닫지 않도록 정리하고, 새로운 문장 재생 시 이전 음성을 취소합니다. 음원 파일이나 Kokoro 엔진은 변경하지 않았습니다.

## 검증

- 단위/회귀159개 통과: 리그 경계, 확률 구간35%, 체험 재화 차감/중복 처리, 서버 얼굴 검증/계정 스냅샷 복원을 포함합니다.
- 새 브라우저 검사7개 통과, Windows WebKit Web Audio 미지원1개 제외. Chromium/WebKit 데스크톱 및 모바일 가로(visualViewport330px, 시스템 UI 여백 포함)의 탭/방 페이지/튜토리얼/체험 상자/UI 높이를 검사했습니다.
- 서로 독립된 실제 브라우저 세션2개로 홈 방 목록에서 생성/참가/프로필 변경을 확인했습니다. 점수 강제 변경을 사용하지 않은 실제 로컬 WebSocket 통신입니다.
- Chromium에서 실제 Kokoro 파일을 디코딩/재생하고 패널을 터치해 닫은 뒤 원래 음성 길이만큼 재생이 계속되어 종료되는 것을 확인했습니다. 예문 패널용 경기 상태는 UI fixture이며 정상 플레이 증거로 합산하지 않습니다.
- 기존 오디오/예문 회귀7개, 방 생성/방장 이전/대전 시작/진입/작은 뷰포트 회귀6개 통과. 실제 Android/iPhone 스피커 검증은 별도이며 브라우저 모사를 실기기로 부르지 않습니다.
- TypeScript, 운영 빌드, Cloudflare 타입 검사와 Worker dry-run 통과. 서버 프로필 메시지가 추가되어 Cloudflare 운영 서버도 함께 배포합니다.
