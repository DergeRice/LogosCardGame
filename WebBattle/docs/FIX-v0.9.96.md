`shared/store.ts`가 프런트 무료 연출과 서버 유료 구매의 공통 설정이다. 서버 직접 교환도 같은 가격표를 사용한다. 확률 안내에는6종, 별가루 범위, 중복 보상, 천장 없음을 표시한다. 기존 상품/기본 지급/보유품/재화는 재정산하지 않는다. 기존 요청 결과 재전송은 저장된 원래 결과를 사용하며 새 요청부터 변경 규칙을 적용한다.

무료 상자 연출은 현재도 활성화되어 있다. 실제 잔액 차감과 상자 보상 저장은 발생하지 않는다. 직접 별가루 교환은 서버에서 실제 차감한다. 무료 연출을 정상 구매로 전환하는 변경은 이번에 하지 않았다.

## 검증

- 전체 Node 테스트204개 통과. 확률의10,000개 균등 구간 검사, 실버 캐릭터 정확히1%,6종 지급, 상자별 별가루 양 끝값, 중복 고정값,850/500/400/300/200 가격 경계, 위조 가격 거절 및 같은 요청1회 차감 포함.
- 로컬 실제 WebSocket 구매 재전송 검증 포함(시드 지갑 테스트이며 정상 플레이로 번 골드 아님).
- 운영용 빌드, Cloudflare 타입 검사·dry-run 및 실제 Miniflare SQLite 런타임4개 WebSocket 회귀 통과. 이 런타임 검증은 운영 서버 검증과 구분한다.
- Chromium/WebKit의 PC 및 모바일 가로 UI 검증: 새 가격/잔액 부족 버튼/확률6종/보드판 공개4개 시나리오와 기존 무료 상자·프레임 회귀8개. 최초 신규 테스트는 화면에서 숨긴 상품 이름을 텍스트로 찾는 잘못된 단언을 보상 종류 속성 검사로 바로잡았다. 재실행은 결과 폴더 충돌을 피하도록 순차 실행한다. 실제 휴대폰 검증이 아니라 모바일 크기 및 작은 visualViewport 모의 환경이다.
- Cloudflare 배포 버전 `7f7f641e-0825-437a-be07-34c8d366165b`. 배포 후 운영 `/health`는500이어서 실제 운영 계정의 교환 성공은 검증하지 못했다. 앞서 확인된 무료 할당량 제한의 복구를 별도로 확인해야 한다. 프런트 무료 연출 검증은 실제 서버 지급 성공으로 간주하지 않는다.
- Netlify 운영 빌드 및 운영 UI 검증은 Git 푸시 후 실행한다.

분석 스크립트는 새 보드판/가격/중복 보상을 반영해 v0.9.96 결과를 별도 생성한다. 기존 날짜별 보고서와 JSON은 변경 전 기록으로 보존한다. `simulate-store-economy.ts`는 오래된100개 교환 가정을 재사용하지 않도록 현재 스크립트로 연결한다.
