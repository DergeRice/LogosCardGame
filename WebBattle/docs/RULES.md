### EXCHANGE

EXCHANGE 보유자는 왼쪽에서 교환할 자기 카드 1장, 오른쪽에서 다른 모든 참가자의 손패 중 원하는 카드 1장을 고릅니다. 현재 경기 규칙에서는 손패 앞면이 참가자에게 공개됩니다. 교환 카드와 손패 버전을 담은 별도 조회 응답은 EXCHANGE 보유자에게 전송됩니다. 선택한 카드의 소유자에게 요청이 자동으로 전달됩니다. 상대는 정확히 그 카드 쌍을 수락하거나 `명사 필요`, `동사 필요`, `+ 카드 요청`, `x 카드 요청`, `무시하기` 중 하나로 거절합니다. 거절 사유는 요청자에게 전달됩니다. 서버는 교환 시 손패 버전·카드 소유·연결 상태를 다시 확인합니다. 거절되어도 사용한 EXCHANGE 카드는 돌아오지 않습니다.

사용자가 정한 규칙: 빠른시작, 4인 상한, 공용 덱, 최초 5장, 40초 자동 배분과 전원 동의 즉시 배분, 고 이후 최고점 주도권, 20점 초과 득점, 3고 상한과 2·3·4배, 레이팅 도입.
구현 기본값: 6초 대기, 혼자면 AI 1명, 39종 활성화 구성, 보상 산식, Elo 산식 및 임시 기록. 원본 Unity의 점수/승패 규칙이라고 주장하지 않습니다.

상단 숫자·색상·별은 점수에 사용하지 않습니다. 현재 덱에는 원본에 인쇄된 ×2, +1, +2, +3 효과 카드를 넣었습니다. ÷2·감점·Exchange/Protect/Rob/Get 등은 이번 덱에 넣지 않습니다. 후속 요청으로 카드 전체 디자인을 원본 그대로 표시하며, 인정 구간에 포함된 카드의 ×/+효과만 합산하며 결과에 계산식을 표시합니다. Do, not, 전치사, 조동사, 부사, Very는 현재 덱에서 제외합니다.

## 판정 범위 (현재)

현재는 `shared/LearningLocalGrammarChecker.ts`의 **CheckPlayableSegment(sequence, false)**가 기준입니다. VB 단독 명령문, 최대 길이 우선·앞 구간 우선, 원본의 모든 보조 함수와 19종 품사를 보존합니다. 전체 문장이 맞지 않아도 인정되는 연속 구간이 있으면 해당 구간 점수가 20점을 초과할 때만 득점·소모합니다. [상세 동작과 품사 매핑](UNITY-GRAMMAR.md)

아래 문형은 기본적인 플레이 예시이며, **허용 조합의 전체 목록이나 판정기의 제한 조건이 아닙니다.**

```
명사구 = 대명사 | 셀 수 없는 명사
       | (관사 | 소유격) [형용사] (셀 수 있는 명사 | 셀 수 없는 명사)

1형식 = 명사구 + 일반동사
2형식 = 명사구 + Be동사 + (명사구 | 형용사)
3형식 = 명사구 + 일반동사 + 명사구
4형식 = 명사구 + 일반동사 + 명사구 + 명사구
5형식 = 명사구 + 일반동사 + 명사구 + 형용사
```

- 가장 긴 유효 연속 구간을 인정하며 동률이면 앞 구간을 택합니다. 인정 구간의 시작/끝 카드 위치를 표시합니다. 내부 인덱스는 0 기반, UI는 1 기반.
- 일반동사는 자동사·타동사·수여동사 등을 아우르는 추상 카드입니다. 개별 동사가 어느 문형을 허용하는지는 판단하지 않습니다.
- 현재 덱의 정관사 그림은 DT_THE로 매핑합니다. DT_AN은 판정기에서 별도로 지원합니다.
- 인칭·수·격·a/an·시제·어휘 의미·주어 동사 일치 검증을 하지 않습니다. 영어 자연어 전체의 정확성 판정기가 아닙니다.
- 외부 AI API나 LLM을 호출하지 않습니다.

## AI

자기 손패만 함수에 넘겨 문형에 맞는 카드 배열 후보를 검색합니다. 문법에 맞지 않는 접두 배열로 탐색 예산을 낭비하지 않게 짧은 문형부터 조합하고 서버와 동일한 `judge`를 호출합니다. 쉬움은 3장 이내의 첫 유효 후보를, 보통/어려움은 탐색한 후보 중 높은 점수를 선택합니다.

| 난이도 | 행동 생각 간격 | 탐색 노드 상한 | 최대 카드 |
|---|---:|---:|---:|
| 쉬움 | 6.5초 | 100 | 3 |
| 보통 | 4.3초 | 900 | 8 |
| 어려움 | 2.6초 | 5000 | 8 |

탐색 1회는 추가로 8ms 제한입니다. 유효하며 20점을 초과하는 조합을 못 찾으면 필요한 경우 AI가 추가 지급을 요청합니다. AI는 다른 플레이어의 요청에 동의합니다. 자동 매칭은 보통 난이도를 사용합니다. AI는 자기 손패로만 제출하며 고 주도권 획득 후 1.8초 뒤 최대 3고까지 고를 선택하고 이후 스톱합니다. AI의 시간 제한은 서버 부하 보호용이므로 동일 손패에서 매번 같은 선택을 보장하지는 않습니다. 문법 판정 결과는 결정적입니다.

## 남은 기획 결정

1. 인쇄 카드 특수효과·별·수치를 전투에 다시 넣을지.
2. 나머지 품사와 부정문·의문문을 확장할지.
3. 문법 학습용 게임과 경쟁 게임 중 점수/손패 밸런스의 우선순위.
4. 양쪽 모두 장기 이탈한 경기를 무승부 처리할지. 현재는 최초 유예 만료 플레이어의 기권 처리.
5. 영구 계정·장기 레이팅 기록 도입 여부. Cloudflare SQLite로 경기/세션 재시작 복구는 구현했지만, 방 밖에서 연결이 끊긴 세션은 1시간 비활동 후 정리합니다.

## 2026-09-27 점수 정정

형식 보너스를 삭제하고 인정 카드당 1점으로 변경했습니다. 예: 5장 ×2 +3 = 13점. ×2가 두 장이면 5×2×2, +3이 두 장이면 마지막에 +3+3. 카드 배치 순서와 무관하게 곱셈을 먼저 수행합니다. 고 배율은 완성된 문장 점수 전체에 적용합니다. 한 문장 점수가 20점을 초과해야 득점하고 누적 최고점에 따라 고/스톱 주도권을 확인합니다.

효과 종류와 원본 이미지 좌표는 shared/rules.ts의 VARIANTS에서 연결하며, 활성화한 그림 34종을 각 1장만 넣으며 같은 경기 안에서 재사용하지 않습니다. 서버가 보유한 카드 ID로만 효과를 조회합니다. 문법 판정 코드는 변경하지 않았습니다.
