# v0.9.81 — 사용자 제공 조작 아이콘

Show.png, Card Hand.png, CardIcon.png, Chat.png 4개를 사용자 Downloads에서 읽어 public/icons/controls에 512×512 투명 PNG로 축소했습니다. Lanczos3 리사이즈와 PNG 압축을 사용했으며 원본 크기 1254×1254의 형태·여백·투명도를 보존하고 원본 파일을 덮어쓰지 않았습니다. 합계 474,510 → 52,211바이트입니다.

- HandFan: 모아 둔 상태에서 Show로 수평 펼치기, 펼친 상태에서 Card Hand로 모으기. 동일 컴포넌트를 사용하는 연습 모드에도 적용합니다.
- 대전 참가자 카드 숫자 왼쪽에 CardIcon을 표시합니다. 기존 손패+필드 장수 계산을 유지합니다.
- 내 손패 아래 감정표현 열기 버튼에 Chat을 표시합니다. 장착한 4개 감정표현과 실제 전송은 유지합니다.
- 공통 ControlIcon과 경로 매핑 모듈로 분리하고 게임 시작 전 사전 로드 목록에 4개를 포함했습니다. 버튼 접근성 이름과 터치 영역을 유지합니다.

검증: 프로덕션 빌드·TypeScript 검사 통과. PNG 4개 모두 메타데이터 512×512, 알파 채널 존재를 확인했습니다. Playwright Chromium/WebKit의 PC·모바일 가로 관련 시나리오 4개 통과. 실제 표시영역이 844×330이고 상단 시스템 영역 20px인 조건도 포함했습니다. 이미지 로드·자연 크기·화면 표시 크기·펼치기/모으기 전환·카드 숫자/아이콘·감정표현 선택 및 표시·스크롤 잠금·클라이언트 오류를 검사했습니다. 이 화면 검사는 서버 상태 fixture를 사용했으며 새 실전 경기 완료로 보고하지 않습니다. 실물 휴대폰 검증은 하지 않았습니다.
