# 품사 조합당 대표 예문 1개 — 2026-10-15

## 산출물

- `examples.csv`: Excel에서 읽는 UTF-8 BOM CSV. 품사 식별자, 형식, 영어, 한국어, 현재 공용 덱 구성 가능 여부.
- `examples.jsonl`: 조합당 1개 기계 처리용 자료. 그림·가감산 효과가 달라도 같은 품사로 묶고 순서/반복은 유지합니다. 영어 어휘 변형 index=0을 고정했습니다.
- `summary.json`: 건수, 중복 제거, 기존 음원 대조, 추정 용량.

조사 범위 45,890개는 길이 1~5 전체와 최대 15장의 구조 생성 검사를 합친 것으로, 모든 15장 배열의 전수 목록이 아닙니다. 그중 현재 덱의 종류·물리적 카드 장수로 만들 수 있는 것은 24,155개입니다. 전체 확장 목록도 추후 카드 추가를 위해 보존합니다.

검사한 모든 항목은 대전 판정기가 전체 구간을 인정합니다. 영어 45,890개는 서로 다르며, 조합과 문장은 각각 1:1입니다. 예문 생성 누락은 0입니다. 이는 판정·생성 자동 검사이며 45,890문장의 의미/번역을 사람이 모두 검수했다는 뜻은 아닙니다. `reviewed:false`를 유지합니다.

기존 547개 Kokoro 음원과 이번 index=0 문장 중 겹치는 것은 143개입니다. 이번 작업에서 대량 음원 파일을 만들거나 게임의 출력 문장을 index=0으로 바꾸지는 않았습니다. 현재 운영은 기존 547문장 음원 그대로입니다.

재현(PowerShell):

```powershell
$env:AUDIT_EXPORT_ONE='1'
npx tsx scripts/audit-example-coverage.ts
Remove-Item Env:AUDIT_EXPORT_ONE
```

## 예상 용량

기존 547 MP3의 총 텍스트 길이 대비 파일 크기를 비례 적용했습니다. 실제 생성 전 추정이므로 긴 문장의 발음 속도/압축률에 따라 달라집니다.

| 범위 | 문장 수 | 추정 MP3 용량 |
|---|---:|---:|
| 현재 덱에서 구성 가능 | 24,155 | 약 577 MB |
| 엔진 확장 포함 전체 | 45,890 | 약 1.18 GB |

음원 전체를 묶어 내려받지 않고 현재 문장 1개만 요청합니다. 전체 기준 평균은 약 26 KB로 예상합니다. 26 KB의 순수 전송 시간은 1 Mbps에서 약 0.21초이며 DNS/TLS·서버/네트워크 왕복 시간은 별도입니다. 캐시·다음 문장 선로딩을 사용하되 시작 지연 시 경기를 막지 않는 정책을 유지해야 합니다.

## 저장 권장 구조

- Netlify: 게임 HTML/JS/CSS.
- Cloudflare 경기 서버: 방·점수·재접속 상태.
- Cloudflare R2 Standard: 해시 이름의 MP3 객체. 게임 서버/대전 Durable Object를 경유하지 않고 별도 오디오 CDN에서 제공.
- 조합 → 문장 → 파일의 색인은 품사 접두어/해시로 나누어 필요한 조각만 로딩. 45,890행의 전체 자료를 게임 첫 화면에서 읽지 않습니다.
- 사용자 기기는 재생한 파일을 브라우저에 캐시. 잘못된 URL의 무한 조회나 공개 목록 열거를 피합니다.

2026-10-15 공식 가격 기준 R2 Standard는 월 10 GB-month 저장·Class A 100만 회·Class B 1,000만 회 무료, 인터넷 전송료 0입니다. 기존 계정의 다른 R2 사용량과 합산됩니다. 무료량을 넘으면 자동으로 비용이 생길 수 있으며 R2 구독 활성화에는 checkout 과정이 있습니다. 이번 작업에서 새 구독을 열거나 결제 설정을 변경하지 않았습니다.

- 가격: https://developers.cloudflare.com/r2/pricing/
- 구독: https://developers.cloudflare.com/r2/get-started/
- 운영 공개/캐시: https://developers.cloudflare.com/r2/buckets/public-buckets/

운영용은 R2 사용자 지정 도메인과 CDN 캐시가 권장됩니다. `r2.dev`는 개발 전용으로 속도 제한이 있고 운영 CDN 대용으로 안내하지 않습니다. 도메인이 없으면 별도 Workers 공개 경로도 설계할 수 있지만 Workers 호출 한도가 추가로 적용됩니다.
