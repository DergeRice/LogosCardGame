# v0.9.101 — 배경 분리와 캐릭터 프로필

## 동작

- `store.background`: 홈 꾸미기용 홈 배경. `store.board`: 인게임 배경. 기존 키/상품ID를 유지하고 독립적으로 장착한다. 프로필 보관함에도 보드판을 추가했으며 로컬 대체 저장을 읽을 때에도 board를 복구한다.
- 캐릭터를 장착하면 홈 메인 캐릭터와 프로필 사진이 같은 캐릭터 상품 이미지를 사용한다. 프레임은 그 위에 겹친다. 프로필 설정은 현재 캐릭터 연동을 안내하고, 치장4개 탭에서 바꾸도록 한다.
- 서버가 공개 참가자/친구/랭킹 데이터에 `characterId`와 `frameId`를 포함한다. 클라이언트는 카탈로그의 해당 종류 ID만 이미지로 해석하며 임의 URL을 받지 않는다. 대기방·매칭·대전·결과 친구목록·랭킹·친구 초대·ROB/EXCHANGE에도 연결한다. ROB 피해 알림은 행동 당시 외형을 보존한다.
- 외형이 없는 이전 데이터/AI는 기존 품사별 프로필로 대체 표시한다. AI 행동 때문에 새 치장 계정 레코드가 생기지 않게 했다. 공개용 외형 필드는 기존 치장 저장에서 읽으며 별도 주기 저장이나 새 서버를 추가하지 않는다.
- 상품·가격·상자 확률·기존 보유품/잔액/프로필 커스텀 원본은 삭제하지 않는다. 보드판을 바꾸어도 홈 배경과 캐릭터는 바뀌지 않는다.

## 검증

- Node 테스트207개. 독립 장착/미보유 거절/친구·랭킹·방 상대에게 장착 캐릭터 전송/스냅샷 복구 포함. 인벤토리와 랭킹 자격은 로컬 테스트용 시드이며 운영 사용자 변경이 아니다.
- Chromium/WebKit의 PC/모바일 가로에서4개 치장 탭, 홈/프로필 사진 연동, 별도 홈 배경과 인게임 배경, 프레임 겹침 검사4개와 프레임 회귀4개. UI 서버 상태는 모의 응답이며 실제 휴대폰 검증이 아니다.
- 운영 빌드/Cloudflare 타입 및 실제 Miniflare4개 WebSocket 회귀. Git 푸시 후 운영 빌드와 UI를 재확인한다.
