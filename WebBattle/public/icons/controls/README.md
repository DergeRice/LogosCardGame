# 대전 조작 아이콘

사용자가 제공한 PNG를 원본 형태와 투명 배경을 유지해 512×512로 축소했습니다. Downloads 원본은 변경하지 않았습니다.

| 파일 | 사용 위치 | 원본 이름 |
|---|---|---|
| show.png | 손패를 수평으로 펼치는 버튼 | Show.png |
| card-hand.png | 펼친 손패를 다시 모으는 버튼 | Card Hand.png |
| card-count.png | 대전 프로필의 보유 카드 숫자 옆 | CardIcon.png |
| chat.png | 내 손패 아래 감정표현 열기 버튼 | Chat.png |

재가공: WebBattle에서 `node scripts/import-control-icons.mjs` 실행. 기본 입력 폴더는 현재 사용자 Downloads이며 별도 입력 폴더를 첫 번째 인자로 지정할 수 있습니다. 출력 4개 합계 52,211바이트. 512px는 에셋 해상도이고 실제 화면에서는 조작 버튼과 카드 장수에 맞춰 작게 표시합니다.
