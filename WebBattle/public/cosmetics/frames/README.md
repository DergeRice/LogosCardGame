# 사용자 제공 프로필 프레임

`D:/download/img (1).png`부터 `img (30).png`까지를 같은 번호의 `style-01.webp`~`style-30.webp`로 연결합니다. 512×512, 비율 유지, 투명 배경 및 중앙 구멍 유지, WebP quality 88/alphaQuality 100입니다. 원본 PNG는 수정하지 않았습니다.

30개 운영 파일 합계 1,546,008바이트(원본 23,868,763바이트 대비 약93.5% 감소). `npm run cosmetics:build`가 기존 카탈로그 생성 방식으로 `frame-style-01`~`frame-style-30`을 등록합니다. 화면에서 프레임 이름은 숨기지만 내부 ID와 접근성용 이미지 설명은 유지합니다.

상점/보관함/보상에서는 캐릭터 위에 프레임을 겹쳐 미리 보여 줍니다. 장착 상태는 기존 store.frame에 저장되며 경기 참가자에게는 서버가 선택한 frameId만 전달합니다. 임의 경로나 미보유 프레임을 클라이언트 입력으로 공개하지 않습니다.
