아직 안 된 것 / 확인할 것

  • 광고는 미연결. 하루 최대 3회 추가 개봉 계획과 연동 요건만 README에 기록.
  • 캐릭터별 전용 대사 10종씩은 미작성. 공통 30개와 추후 추가할 구조까지만 있음.
  • 50개짜리 상점 상품은 없음. 현재 40·100개 상품이 있고, 50개 결과를 10개씩 보여주는 화면은 별도 검증. 가격은 임의로 추가하지 않음.
  • 등급은 아이템 종류 기준. 개별 아이템마다 별도 등급을 부여한 체계는 아직 없음.
  • 실제 휴대폰 검증은 아직. 모바일 가로·세로 브라우저 시뮬레이션으로 확인.

발견해서 고친 현상

장착창·상자 결과창이 하단 메뉴와 겹침 → 독립 레이어로 이동.

캐릭터 시트의 귀·리본 경계가 맞닿음 → 윤곽과 경계 보정 후 전체 이미지 확인.

상자/장착창의 작은 화면 → 목록 영역만 줄이고 하단 버튼 유지. WebKit 닫기 후 초점 복귀도 보정.

검증

단위 테스트 260개 통과. Chromium·WebKit의 데스크톱/모바일 세로·가로 장착 검사 통과.

이전 업데이트도 서버 검사와 운영 배포를 확인함. 실제 휴대폰 검증은 아직이며, 빌드의 기존 번들 크기 경고는 남아 있음.
